======================================================================
ОКРУЖЕНИЕ
======================================================================

Session, workPart и все публичные имена из nx_primitives уже подставлены
автоматически ДО твоего кода.

В пространстве имён гарантированно доступны:

  Triangle, Parallelogram, Polygon, Circle, Line,
  Extrude, Fillet, Union, Subtract, Intersect, Boolean,
  Frame, Hide, rect_profile,
  attachment_seam, edges_after_boolean, edges_in_box, edges_near

НЕ пиши:
- import NXOpen
- from nx_primitives import ...
- theSession = NXOpen.Session.GetSession()
- workPart = theSession.Parts.Work

Начинай код сразу с построения геометрии.

Можно свободно использовать:
  Triangle.by_3_sides(...)
  Triangle.by_2_sides_and_angle(...)
  Triangle.by_2_angles_and_side(...)
  rect_profile(...)
  Parallelogram(...)
  Polygon(...) / Polygon.on_frame(...)
  Circle(...) / Circle.on_frame(...)
  и все методы Extrude (anchor, center_frame, attach, attach_plate, bottom_edges, top_edges, vertical_edges, edges_on и т.д.)

Никогда не используй "голый" NXOpen напрямую.
Всё строится ТОЛЬКО через классы и функции, перечисленные выше.

======================================================================
ЧТО ТАКОЕ Extrude И ПОЧЕМУ ОН ЦЕНТРАЛЬНЫЙ ОБЪЕКТ БИБЛИОТЕКИ
======================================================================

Любое тело в этой библиотеке строится в два шага:
1. Строится плоский 2D-контур (Polygon / Circle / Triangle /
   Parallelogram) — это ЛИНИИ, а не тело.
2. Контур(ы) передаются в Extrude(workPart, [контур, ...], height,
   direction) — это создаёт объёмное тело выдавливанием.

Extrude(workPart, profiles, height, direction=(0,0,1))
    profiles  — список профилей. ПЕРВЫЙ — внешний контур тела.
                ОСТАЛЬНЫЕ — вычитаемые контуры (отверстия) внутри него.
    height    — высота выдавливания (число, не строка).
    direction — вектор (x,y,z), КУДА растёт тело от плоскости контура.
                По умолчанию вверх (0,0,1).

Результат — объект Extrude с полями и методами:
    .body              — NXOpen.Body (готовое тело)
    .profiles          — список переданных профилей
    .height            — высота (float)
    .direction         — направление выдавливания (tuple)
    .profile_labels    — список словарей {{имя_вершины: 3D-точка}},
                          отдельный словарь на каждый профиль (внешний
                          контур — индекс 0, отверстия — 1, 2, ...)
    .labels            — то же самое что profile_labels[0] (для удобства)

БУКВЕННАЯ РАЗМЕТКА ВЕРШИН (создаётся автоматически для каждого профиля):
    Вершины контура ДО выдавливания (нижний ряд): a, b, c, d, ...
    (в том порядке, в котором вершины были заданы при построении контура)
    Те же вершины ПОСЛЕ выдавливания (верхний ряд, сдвинуты на height
    вдоль direction): a1, b1, c1, d1, ...

    Работает для контура любого числа сторон (треугольник -> a,b,c/
    a1,b1,c1; шестиугольник -> a,b,c,d,e,f/a1,b1,c1,d1,e1,f1 и т.д.)

ИМЕНА РЁБЕР (используются в Fillet и во многих методах):
    "ab", "bc", "cd", "da"        — рёбра нижнего контура (между
                                     соседними вершинами нижнего ряда)
    "a1b1", "b1c1", "c1d1", "d1a1" — рёбра верхнего контура
    "aa1", "bb1", "cc1", "dd1"      — вертикальные рёбра (соединяют
                                       нижнюю вершину с соответствующей
                                       верхней)

    Порядок вершин в имени ребра ВСЕГДА "нижняя_метка -> следующая по
    контуру" (или "нижняя -> верхняя" для вертикальных). Ребро всегда
    называется двумя соседними метками подряд, например "bc", не "cb".

    Индекс профиля (profile_index): 0 — внешний контур (по умолчанию,
    можно не указывать), 1, 2, ... — отверстия, в порядке их передачи
    в список profiles при вызове Extrude.

    Для ребра НЕ внешнего контура используй кортеж (имя, индекс),
    например ("aa1", 1) — вертикальное ребро первого отверстия.

    ДЛЯ СКРУГЛЕНИЯ ВСЕХ РЁБЕР ОДНОГО ТИПА (весь нижний контур / весь
    верхний контур / все вертикальные рёбра) НЕ перечисляй имена
    вручную — используй готовые методы:
        extrude.bottom_edges(profile_index=0)   -> ["ab","bc","cd","da",...]
        extrude.top_edges(profile_index=0)      -> ["a1b1","b1c1",...]
        extrude.vertical_edges(profile_index=0) -> ["aa1","bb1",...]
    Они сами определяют число сторон контура (работают для треугольника,
    шестиугольника и т.д.), поэтому безопаснее и короче, чем писать
    список имён самому.

--- 2D-профили (создают ЛИНИИ, ещё не тело) ---

Circle(workPart, radius, center=(0.0,0.0), normal=(0.0,0.0,1.0))
    center может быть (x,y) — тогда окружность лежит в плоскости XY
    на z=0, либо (x,y,z) вместе с normal — окружность в произвольной
    плоскости (например вертикальной).

Circle.on_frame(workPart, radius, frame, u=0.0, v=0.0)
    Окружность в плоскости frame, центр в точке frame.point(u, v).
    ЭТО ПРЕДПОЧТИТЕЛЬНЫЙ способ ставить отверстия/окружности на грани
    существующего тела — см. раздел про holes и attach().

Triangle.by_3_sides(workPart, side_a, side_b, side_c, center=(0,0), frame=None)
Triangle.by_2_sides_and_angle(workPart, side_a, side_b, angle_ab, center=(0,0), frame=None)
Triangle.by_2_angles_and_side(workPart, angle_a, angle_b, side_ab, center=(0,0), frame=None)
    Треугольник. НЕ создавай Triangle через __init__ напрямую (нужны
    явные 3D-точки p1,p2,p3) — используй один из фабричных методов
    выше. Равносторонний/равнобедренный/прямоугольный — частные случаи
    этих же методов с соответствующими числами.

Parallelogram(workPart, side_a, side_b, angle, center=(0.0,0.0), frame=None)
    side_a — первая сторона, side_b — вторая (под углом angle градусов
    к первой). angle=90 -> прямоугольник (или квадрат, если
    side_a==side_b). center — где сидит ЦЕНТР фигуры (не угол!) в
    локальных координатах (или в координатах frame, если он передан).
    Контур без frame лежит в плоскости XY (z=0).

Polygon(workPart, vertices)
    Многоугольник по явному списку 3D-точек [(x,y,z), ...], в порядке
    обхода. Вершины становятся метками a,b,c,d... в ЭТОМ порядке —
    порядок точек определяет, какое ребро как называется впоследствии
    (важно, когда конкретное ребро/грань должны с чем-то совпасть,
    см. пример 4 ниже).

Polygon.on_frame(workPart, frame, local_vertices)
    То же самое, но точки заданы в ЛОКАЛЬНЫХ (u,v) координатах frame
    (frame.points() применяется автоматически). Самый частый способ
    построить произвольную (не прямоугольную) фигуру на готовом Frame.

--- Frame — локальная система координат ---

Frame(origin, u, v, normal=None)
    origin — точка (x,y,z). u, v — базисные направления плоскости
    (нормализуются автоматически). normal — направление "толщины"
    (если не задано, вычисляется как u×v).
    .point(u=0.0, v=0.0, w=0.0)  -> 3D-точка = origin + u*U + v*V + w*normal
    .points(local_xy)            -> список точек для списка (u,v)-пар

--- Тело (Extrude) и его методы для стыковки новых деталей ---

Extrude.find_edge(name, profile_index=0) -> NXOpen.Edge
    Найти РЕБРО уже построенного тела по буквенному имени (для Fillet).
    Если точное совпадение по координатам не найдено (например, ребро
    сдвинулось из-за более раннего Fillet на смежной вершине), метод
    сам пробует fallback-поиск по середине и длине ребра — специально
    заботиться об этом в генерируемом коде не нужно.

Extrude.edge_points(name, profile_index=0) -> (p1, p2)
    3D-координаты начала и конца ребра по имени.

Extrude.vertex(name, profile_index=0) -> (x,y,z)
    3D-координата ОДНОЙ вершины по имени ("a", "b1", ...). Используй,
    когда нужно собрать Frame полностью вручную (редкий случай, см.
    "КОГДА НУЖНО РУЧНОЕ УПРАВЛЕНИЕ" ниже).

Extrude.bottom_edges(profile_index=0) -> list[str]
Extrude.top_edges(profile_index=0) -> list[str]
Extrude.vertical_edges(profile_index=0) -> list[str]
    Готовые списки имён ВСЕХ рёбер соответствующего типа для указанного
    профиля, в порядке обхода, для контура ЛЮБОГО числа сторон.
    Используй их вместо ручного перечисления ["ab","bc","cd","da"] —
    короче и не зависит от того, сколько у контура вершин.

Extrude.inward_direction(edge_name) -> unit vector
    Направление "внутрь" тела от середины ребра, горизонтально
    (перпендикулярно direction). Используется автоматически внутри
    anchor()/attach_plate() — сам по себе почти никогда не нужен.

Extrude.attach_plate(edge_name, length, width, thickness,
                      rise='same', grow='auto', overlap='auto',
                      profile_index=0, holes=None) -> Extrude
    БЫСТРЫЙ способ поставить ПРЯМОУГОЛЬНУЮ пластину, растущую ОТ
    ребра ПЕРПЕНДИКУЛЯРНО (как стенка от края), с автоматическим
    "утапливанием" в родителя на overlap мм, чтобы после Union тела
    гарантированно пересеклись (без зазора/щели). Используй для самого
    частого случая: "поставить стенку/пластину на весь край ребра".
    length=None -> длина = длине самого ребра (стенка во всю длину).
    rise: 'same' (растёт в сторону direction родителя, обычно "вверх"),
          'opposite' (в обратную сторону), или явный вектор.
    grow: 'auto' (толщина растёт внутрь родителя) или явный вектор.

Extrude.anchor(edge_name, profile_index=0, t=0.0, offset=0.0,
               angle=0.0, lift=0.0) -> Frame
    УНИВЕРСАЛЬНАЯ точка+ориентация НА РЕБРЕ. Используй вместе с
    attach(), когда attach_plate не подходит (нужна не вся длина
    ребра, не прямоугольник, конкретный угол наклона, зазор и т.д.)

    t        — позиция вдоль ребра, ДОЛЯ от 0 (первая вершина ребра)
               до 1 (вторая вершина).
    offset   — дополнительный сдвиг вдоль ребра В ММ (после t). Можно
               отрицательный. t=0, offset=8 -> точка в 8мм от начала
               ребра. t=0.5, offset=0 -> точно середина ребра.
    angle    — угол поворота НОВОЙ детали вокруг ОСИ РЕБРА, в градусах:
                 0   -> деталь встаёт в направлении direction родителя
                        (перпендикулярно родителю, "вверх от грани")
                 180 -> в обратную сторону ("вниз от грани")
                 90  -> ложится ПЛАШМЯ, продолжая плоскость родителя
                        (полезно, если родитель горизонтальный и надо
                        пристроить соседнюю плитку в той же плоскости)
                -90  -> деталь растёт ГОРИЗОНТАЛЬНО НАРУЖУ от грани, а
                        направление её собственного выдавливания (её
                        "высота") идёт ВВЕРХ, как у родителя. ЭТО НУЖНО,
                        когда рядом с первым параллелепипедом строится
                        ВТОРОЙ, стоящий на том же полу (обе детали
                        "вертикальные", соприкасаются боковыми гранями)
               Возвращаемый Frame: .u вдоль ребра, .v = "куда растёт
               плоскость фигуры" (см. angle), .normal = направление
               выдавливания (передавай его как direction в Extrude,
               либо оставь по умолчанию в attach()).
    lift     — сдвиг точки вдоль итоговой normal, В ММ. Положительное
               значение отодвигает деталь от грани (зазор, не
               соприкасается), отрицательное — утапливает внутрь.

Extrude.center_frame(profile_index=0, side='same', spin=0.0,
                      du=0.0, dv=0.0, lift=None) -> Frame
    Frame для детали, лежащей ПЛАШМЯ НА ВСЕЙ ГРАНИ (не растущей от
    ребра, а садящейся на плоскость сверху/снизу целиком) — приставки,
    платформы, "боссы", вторая пластина ровно поверх первой.

    side  — 'same' (расти в сторону direction родителя, "сверху") или
            'opposite' ("снизу").
    spin  — поворот детали В ЕЁ СОБСТВЕННОЙ ПЛОСКОСТИ вокруг нормали
            грани, в градусах (0, 90, 180, ...). НЕ путать с наклоном —
            это чисто плоский разворот (например "положить деталь
            поперёк вместо вдоль").
    du,dv — сдвиг ЦЕНТРА детали в плоскости грани (вдоль итоговых u,v,
            уже после spin), в мм, от центра грани родителя.
    lift  — зазор вдоль нормали. По умолчанию (None) = толщине
            родителя (self.height) — деталь садится ВПЛОТНУЮ на
            поверхность родителя, не пересекая её и не паря над ней.
            lift=0 -> деталь стартует ОТ ПЛОСКОСТИ РОДИТЕЛЯ (будет
            наполовину внутри родителя, если growить в его сторону).

Extrude.attach(build, thickness, frame=None, edge_name=None,
               profile_index=0, t=0.0, offset=0.0, angle=0.0,
               lift=0.0, direction=None, holes=None) -> Extrude
    УНИВЕРСАЛЬНОЕ присоединение ЛЮБОЙ фигуры (не только прямоугольник).
    build — функция ОДНОГО аргумента frame, возвращающая Profile,
    например:
        lambda f: rect_profile(workPart, f, length=20, width=10)
        lambda f: Circle.on_frame(workPart, 5.0, f, u=10, v=20)
        lambda f: Polygon.on_frame(workPart, f, [(0,0),(20,0),(10,15)])
        lambda f: Parallelogram(workPart, side_a=10, side_b=10, angle=90, frame=f)

    Передавай ЛИБО frame=... (готовый Frame от anchor()/center_frame()),
    ЛИБО edge_name + t/offset/angle/lift (тогда attach() сам вызовет
    anchor() с этими параметрами). Если frame передан явно — остальные
    позиционные параметры (edge_name, t, offset, angle, lift)
    игнорируются.

    direction — направление выдавливания НОВОЙ детали. По умолчанию —
    нормаль frame. Переопределяй ЯВНО, когда нужно направление, отличное
    от frame.normal — например, деталь должна торчать НАРУЖУ от грани,
    а не внутрь (см. пример 3: `direction = tuple(-c for c in frame.normal)`).

    holes — список функций frame->Profile (та же сигнатура что build) —
    вычитаемые отверстия внутри новой детали (тот же frame, что и у
    внешнего контура — поэтому Circle.on_frame(..., f, u=.., v=..)
    внутри lambda всегда МОЖЕТ ссылаться на тот же f).

--- Скругление ---

Fillet(workPart, extrude, edges, radius)
    extrude — объект Extrude, ИСПОЛЬЗУЕТСЯ ДЛЯ ПОИСКА РЁБЕР ПО ИМЕНИ
              (строкам/кортежам в edges). Для готовых NXOpen.Edge не
              используется для поиска, но параметр всё равно ОБЯЗАТЕЛЕН
              (передай любой существующий Extrude, например тело, на
              которое эти рёбра фактически ссылаются).
    edges — список, элементы можно свободно смешивать:
              - строка "ab", "a1b1", "aa1" -> ребро внешнего контура,
                ищется в extrude по имени
              - кортеж ("ab", 1) -> ребро отверстия с индексом 1
              - готовый NXOpen.Edge -> используется как есть (получен
                из merged.new_edges, attachment_seam(...) или
                edges_after_boolean(...))
              - готовые списки от extrude.bottom_edges()/top_edges()/
                vertical_edges() — их можно передавать напрямую как
                edges (это списки строк).
    radius — число.

    МОЖНО делать НЕСКОЛЬКО последовательных вызовов Fillet на одном и
    том же extrude с разными группами рёбер и разными радиусами (например
    сначала вертикальные рёбра радиусом 2, затем верхний контур радиусом
    1) — find_edge сам находит актуальное положение рёбер даже после
    того, как предыдущий Fillet изменил геометрию у общих вершин.

    ВАЖНО про радиус: он должен быть ЗАМЕТНО МЕНЬШЕ, чем самая короткая
    из смежных с ребром размеров (высота детали, ширина грани и т.п.).
    Если radius >= высоты/толщины детали, в которой лежит ребро — NX,
    скорее всего, откажется строить скругление с ошибкой вида
    "невозможно ограничить грань скругления". Если это случилось —
    в СЛЕДУЮЩЕЙ попытке возьми радиус заметно меньше (например вдвое).

    ВАЖНО: если ДВЕ группы рёбер (например vertical_edges присоединённой
детали и рёбра шва) ДЕЛЯТ ОБЩИЕ ВЕРШИНЫ и скругляются ОДНИМ радиусом —
их нужно передать в ОДИН вызов Fillet(workPart, extrude, group1+group2,
radius), а НЕ в раздельные последовательные вызовы. Раздельные вызовы
на общих вершинах вызывают ошибку NX "Невозможно ограничить грань
скругления" — это не значит, что не хватает ещё одного ребра другого
типа, это значит, что рёбра нужно объединить в один вызов.

ЕСЛИ первый аргумент Fillet (extrude) - это тело, которое уже
участвовало как tools в Union/Subtract/Intersect: его .body
suppressed, и искать по нему рёбра напрямую нельзя (см. правило в
разделе про Union/Subtract/Intersect выше). В этом случае:
- сначала получите нужные Edge через extrude.edges_on(merged.body,
  names) / edges_after_boolean(...) / attachment_seam(...);
- вторым аргументом Fillet передайте ЛЮБОЙ ДРУГОЙ АКТИВНЫЙ Extrude
  (обычно target, т.е. тело, в которое всё слилось) - он используется
  только как формальный "якорь", т.к. переданные Edge уже готовы и
  поиск по имени для них не выполняется.

--- Булевы операции ---

Union(workPart, target, tools, tolerance=0.01)
Subtract(workPart, target, tools, tolerance=0.01)
Intersect(workPart, target, tools, tolerance=0.01)
    target, tools — Extrude, готовое NXOpen.Body, или список того и
    другого. Результат — объект с полями:
      .body                — итоговое тело
      .new_edges           — список NXOpen.Edge, появившихся ИМЕННО от
                              этой операции (шов). Передавай напрямую в
                              Fillet(...) как список edges.
      .removed_edges_count — сколько рёбер пропало (для справки).

    ВАЖНО: .new_edges сравнивает "было/стало" по координатам. Если
    присоединяемая деталь стояла ВПЛОТНУЮ (через attach()/center_frame()
    с обычным lift) — её СОБСТВЕННОЕ нижнее (или верхнее) кольцо вершин
    зачастую СОВПАДАЕТ с местом шва, и такое ребро СУЩЕСТВОВАЛО ещё до
    Union (как ребро самой детали) -> .new_edges его НЕ увидит (список
    может оказаться короче ожидаемого или вообще пустым). В ЭТОМ
    случае используй attachment_seam(...) вместо new_edges.

ВАЖНО (общее правило, не только про шов): сразу ПОСЛЕ Union/Subtract/
Intersect тело(а), переданные как tools, становятся SUPPRESSED - NX
физически поглощает их в target. Это значит, что tools.body больше
не активно, и ЛЮБОЙ вызов, использующий tools.body напрямую -
tools.find_edge(...), Fillet(workPart, tools, [...], radius) -
упадёт с ошибкой NX "Операция, запрещенная на подавленном объекте".
Это касается НЕ ТОЛЬКО рёбер шва, но и любых "собственных" именных
рёбер tools - например top_edges()/bottom_edges()/vertical_edges()
присоединённой детали, если их нужно скруглить ПОСЛЕ Union.

Если такие рёбра нужны ПОСЛЕ булевой операции - есть ровно два пути:
1. tools.edges_on(merged.body, names) (или свободная функция
   edges_after_boolean(tools, merged.body, names)) - ищет рёбра по
   заранее сохранённым координатам НА РЕЗУЛЬТИРУЮЩЕМ теле, а не
   через само tools.body. Работает для любых имён, не только шва.
2. Сделать нужный Fillet НА tools ДО вызова Union/Subtract/Intersect,
   пока тело ещё активно (см. пример 2b ниже).

attachment_seam(child, parent_body, profile_index=0, ring="bottom") -> list[Edge]
    Найти рёбра шва по КОНТУРУ child (детали, присоединённой ВПЛОТНУЮ
    через attach()/center_frame()/attach_plate), а не по диффу
    "было/стало". Надёжнее new_edges именно для деталей, посаженных
    заподлицо. child — Extrude ДО объединения (используются только его
    profile_labels, тело ему уже не нужно). parent_body — тело ПОСЛЕ
    объединения (merged.body). ring="bottom" — нижнее кольцо (a,b,c,d,
    обычно это и есть плоскость стыка), "top" — верхнее (a1,b1,...).

    attachment_seam(child, parent_body, ring="bottom") ПОДХОДИТ ТОЛЬКО для
деталей, лежащих ПЛАШМЯ на грани целиком (center_frame-паттерн). Для
деталей, растущих ОТ РЕБРА сбоку (anchor+attach с angle=-90/0/180) —
используй child.contact_edges() вместо attachment_seam. Если спутать
эти два случая — Fillet скруглит не те рёбра (например "пол" пристроя
вместо реальной зоны контакта) без явной ошибки, только визуально
неверный результат.

edges_after_boolean(child, target_body, edge_names, profile_index=0) -> list[Edge]
    Как attachment_seam, но для КОНКРЕТНЫХ именованных рёбер, а не
    всего кольца целиком. edge_names — список имён, например
    ["aa1", "bb1"]. Рёбра, которые после объединения слились с
    соседней гранью и перестали существовать отдельно, тихо
    пропускаются (это нормально, не ошибка).

edges_in_box(body, p_min, p_max) -> list[Edge]
edges_near(body, point, tol=1.0) -> list[Edge]
    Крайний случай — поиск рёбер по абсолютным координатам в
    пространстве. Используй, ТОЛЬКО если new_edges и attachment_seam/
    edges_after_boolean не дали нужного результата (например для очень
    нестандартного шва). Для edges_in_box p_min/p_max — это (x,y,z).

--- Прочее ---

rect_profile(workPart, frame, length, width, u0=0.0, v0=0.0) -> Profile
    Прямоугольник length x width на Frame. ГЛАВНЫЙ параметр — u0, v0:
    они задают, ГДЕ СИДИТ прямоугольник относительно frame.origin, в
    ДОЛЯХ от своего размера:
        u0=0,   v0=0    -> растёт от origin В ПЛЮС по обеим осям
                            (origin = угол прямоугольника). Используй,
                            когда origin УЖЕ стоит на краю/угле грани
                            (например от anchor(edge, t=0)).
        u0=0.5, v0=0.5  -> origin ТОЧНО В ЦЕНТРЕ прямоугольника.
                            Используй для center_frame() (origin и так
                            в центре грани) или anchor(t=0.5) (origin
                            на середине ребра, и надо чтобы деталь была
                            центрирована именно вдоль ребра).
        u0=0.5, v0=0    -> центрирован ПО u (вдоль ребра), но растёт
                            ПО v ОТ origin (не проваливается наполовину
                            "под" грань). Типичный случай: origin на
                            СЕРЕДИНЕ ребра, а деталь должна вставать от
                            него вверх/наружу целиком, а не наполовину
                            в минус.
    Всегда выбирай u0/v0 исходя из того, ГДЕ физически стоит origin
    (край/середина/центр) и КУДА должна расти деталь относительно этой
    точки — расписывай это как отдельный шаг перед вызовом.

Hide(session, *profiles)
    Прячет 2D-кривые перечисленных профилей (не тела!). session уже
    подставлен как theSession. В конце скрипта, где не мешает — обычно
    Hide(theSession, base, *other.profiles, ...) для всех "промежуточных"
    контуров, которые не нужно видеть отдельно от готового тела.

======================================================================
АЛГОРИТМ РЕШЕНИЯ ЗАДАЧИ (следуй по порядку)
======================================================================

1. РАЗБЕЙ запрос на отдельные ТЕЛА (Extrude). Почти каждая "деталь"
   в запросе — это одно построение контура + один Extrude.

2. Первое тело строится "с нуля" (Polygon/Circle/Triangle/Parallelogram
   в явных координатах или в плоскости XY по умолчанию), остальные —
   ПРИСОЕДИНЯЮТСЯ к уже построенным через методы Extrude. НИКОГДА не
   вычисляй координаты присоединяемых деталей вручную — используй
   anchor/center_frame/attach/attach_plate.

   - Прямоугольная пластина/стенка растёт ОТ ВСЕГО ребра перпендикулярно
     -> attach_plate.
   - Что угодно ещё, растущее ОТ РЕБРА (не на всю длину, не
     прямоугольник, под углом, с зазором) -> anchor + attach.
   - Что-то лежащее ПЛАШМЯ на грани целиком (крышка, платформа,
     вторая деталь поверх/под первой) -> center_frame + attach.
   - Нужно, чтобы КОНКРЕТНОЕ именованное ребро новой детали (не "ab",
     а например "cd") касалось родителя -> контролируй ПОРЯДОК точек в
     build-функции (Polygon.on_frame/явный список), см. пример 4.
   - Нужно направление, отличное от frame.normal по умолчанию (деталь
     растёт НАРУЖУ, а не туда, куда "естественно" смотрит frame) ->
     передай direction явно в attach().

3. Если тела нужно СЛИТЬ в одно (явно попросили "объединить"/"единое
   тело"/собираешься резать через получившуюся геометрию) -> Union
   ПОСЛЕ того, как все присоединения сделаны. Если просто "рядом стоят"
   без явного требования единого тела — Union не обязателен, оставь
   отдельными Extrude.

4. Скругления и отверстия — В ПОСЛЕДНЮЮ очередь, когда геометрия уже
   собрана:
   - Отверстие, известное ЗАРАНЕЕ (до Extrude) -> добавь его как
     дополнительный профиль в holes= у attach()/attach_plate(), либо
     вторым (третьим...) элементом списка profiles у прямого Extrude().
   - Скругление ВСЕХ рёбер одного типа (весь нижний/верхний контур,
     все вертикальные) -> используй extrude.bottom_edges() /
     extrude.top_edges() / extrude.vertical_edges() вместо ручного
     перечисления имён.
   - Скругление именованных рёбер ОДНОГО тела (ещё до всяких Union) ->
     Fillet(workPart, тело, ["имя1", "имя2", ...], radius).
   - Если нужны РАЗНЫЕ радиусы для разных групп рёбер одного тела
     (например вертикальные — radius=2, верхние — radius=1) — делай
     ДВА (или больше) отдельных вызова Fillet подряд, каждый со своей
     группой и радиусом. Порядок вызовов можно не продумывать особо:
     find_edge сам находит рёбра даже после того, как предыдущий Fillet
     изменил геометрию у общих вершин.
   - Скругление ШВА после Union -> сначала merged.new_edges; если список пуст/короче ожидаемого (деталь была присоединена вплотную) -> attachment_seam(child, merged.body) или edges_after_boolean(child, merged.body, ["имя1", ...]). - Скругление ЛЮБЫХ ДРУГИХ (не шовных) именованных рёбер присоединённой детали (например top_edges() у boss) ПОСЛЕ Union -> НИКОГДА не Fillet(workPart, child, child.top_edges(), radius) - child.body к этому моменту suppressed. Либо сделайте этот Fillet НА child ДО Union (см. пример 2b), либо получите Edge через child.edges_on(merged.body, child.top_edges()) и передайте их в Fillet(workPart, target, ..., radius) вместе со швом одним вызовом (если радиус совпадает) или отдельным вызовом (если радиус другой).
   - Следи, чтобы radius был заметно меньше самого маленького смежного
     размера (высоты детали, ширины грани и т.д.).

5. Всегда используй float-совместимые числа (можно int, конвертация
   внутри библиотеки уже есть), не строки.

6. ПЕРЕД тем как написать вызов anchor()/attach()/center_frame() с
   нетривиальными параметрами — мысленно проговори (и запиши коротким
   комментарием прямо над строкой): где физически стоит origin
   (край/середина/центр грани или ребра), куда должна расти новая
   деталь относительно этой точки, и с какой стороны/гранью она
   касается родителя. Если не можешь коротко это сформулировать —
   скорее всего параметры выбраны неверно, попробуй другую комбинацию
   u0/v0/angle/side/spin, а не первую попавшуюся.

--- Пример 1: прямоугольная пластина + стенка на весь край + Union + Fillet шва ---

base = Parallelogram(workPart, side_a=60.0, side_b=40.0, angle=90.0)
plate = Extrude(workPart, [base], height=3.0, direction=(0.0,0.0,1.0))
wall = plate.attach_plate("ab", length=None, width=20.0, thickness=3.0)
merged = Union(workPart, plate, wall)
Fillet(workPart, plate, merged.new_edges, radius=1.0)

--- Пример 2: приставка (boss) плашмя на плите + Union + Fillet шва
    (new_edges тут даст 0 - деталь вплотную, нужен attachment_seam) ---

base = Parallelogram(workPart, side_a=60.0, side_b=60.0, angle=90.0)
plate = Extrude(workPart, [base], height=3.0, direction=(0.0,0.0,1.0))
boss = plate.attach(
    lambda f: rect_profile(workPart, f, length=20.0, width=20.0, u0=0.5, v0=0.5),
    thickness=3.0,
    frame=plate.center_frame(side='same'),
)
merged = Union(workPart, plate, boss)
seam = attachment_seam(boss, merged.body)
Fillet(workPart, plate, seam, radius=1.0)

--- Пример 2b: приставка (boss) плашмя на плите, где нужно скруглить НЕ ТОЛЬКО шов, но и её собственные верхние рёбра - оба варианта ---

Вариант А (рекомендуется, когда радиусы разные): скругляем top_edges
босса ДО Union, пока boss.body ещё активен, а шов - после Union.

base = Parallelogram(workPart, side_a=60.0, side_b=60.0, angle=90.0) plate = Extrude(workPart, [base], height=3.0, direction=(0.0,0.0,1.0)) boss = plate.attach( lambda f: rect_profile(workPart, f, length=20.0, width=20.0, u0=0.5, v0=0.5), thickness=6.0, frame=plate.center_frame(side='same'), ) Fillet(workPart, boss, boss.top_edges(), radius=1.0) # до Union - boss.body ещё активен merged = Union(workPart, plate, boss) seam = attachment_seam(boss, merged.body) Fillet(workPart, plate, seam, radius=1.0) # шов - только после Union, через attachment_seam

Вариант Б (если радиус общий и хочется одним вызовом): top_edges
и шов - оба ПОСЛЕ Union, top_edges - через edges_on (не find_edge).

merged2 = Union(workPart, plate, boss) top = boss.edges_on(merged2.body, boss.top_edges()) # НЕ Fillet(workPart, boss, ...) - boss.body suppressed seam2 = attachment_seam(boss, merged2.body) Fillet(workPart, plate, top + seam2, radius=1.0)

--- Пример 3: маленький прилив, торчащий НАРУЖУ от боковой грани
    (direction нужно явно перевернуть, т.к. anchor() по умолчанию
    растит внутрь родителя) ---

base = Parallelogram(workPart, side_a=60.0, side_b=40.0, angle=90.0)
box = Extrude(workPart, [base], height=15.0, direction=(0.0,0.0,1.0))
frame = box.anchor("ab", offset=8.0, angle=0.0)
outward = tuple(-c for c in frame.normal)
tab = box.attach(
    lambda f: rect_profile(workPart, f, length=8.0, width=10.0, u0=0.0, v0=0.0),
    thickness=7.0,
    frame=frame,
    direction=outward,
)

--- Пример 4: второй параллелепипед, стоящий РЯДОМ с первым (обе
    "вертикальные"), с контролем, каким именно ребром он касается
    (angle=-90 у anchor даёт "расти горизонтально наружу, выдавливаться
    вверх"; порядок точек в build перевёрнут, чтобы ребро "cd", а не
    "ab", было ближним/касающимся) ---

base = Parallelogram(workPart, side_a=60.0, side_b=40.0, angle=90.0)
box = Extrude(workPart, [base], height=15.0, direction=(0.0,0.0,1.0))
frame = box.anchor("ab", offset=8.0, angle=-90.0)

def small_profile(f):
    l, w = 8.0, 10.0
    pts = [(l, w), (0.0, w), (0.0, 0.0), (l, 0.0)]  # cd - ближнее ребро
    return Polygon.on_frame(workPart, f, pts)

small = box.attach(
    small_profile,
    thickness=4.0,
    frame=frame,
    holes=[lambda f: Circle.on_frame(workPart, 2.0, f, u=4.0, v=4.0)],
)
Fillet(workPart, small, ["aa1", "bb1"], radius=1.5)

--- Пример 5: отверстие сразу при первом построении, без attach ---

base = Parallelogram(workPart, side_a=60.0, side_b=40.0, angle=90.0)
hole = Circle(workPart, radius=5.0, center=(15.0, 10.0))
plate = Extrude(workPart, [base, hole], height=3.0, direction=(0.0,0.0,1.0))
Fillet(workPart, plate, ["ab", "bc", "cd", "da"], radius=1.0)

--- Пример 6: два разных радиуса на одном теле (вертикальные рёбра
    и верхний контур), через готовые group-хелперы вместо ручных имён ---

base = Parallelogram(workPart, side_a=60.0, side_b=40.0, angle=90.0)
hole = Circle(workPart, radius=5.0, center=(0.0, 0.0))
box = Extrude(workPart, [base, hole], height=10.0, direction=(0.0, 0.0, 1.0))
Fillet(workPart, box, box.vertical_edges(), radius=2.0)
Fillet(workPart, box, box.top_edges(), radius=1.0)

======================================================================
КОГДА НУЖНО РУЧНОЕ УПРАВЛЕНИЕ (редко)
======================================================================

Если ни attach_plate, ни attach+anchor/center_frame не покрывают
задачу (совсем нестандартная стыковка) — собери Frame вручную из
известных точек:

p = box.vertex("b1")
frame = Frame(origin=p, u=(1,0,0), v=(0,0,1), normal=(0,1,0))
piece = box.attach(lambda f: rect_profile(workPart, f, 10, 10), thickness=2.0, frame=frame)

Это ПОСЛЕДНИЙ вариант — предпочитай anchor()/center_frame(), они уже
считают направления автоматически и реже дают геометрически неверный
результат.

class Profile:
    # Базовый класс всех двумерных профилей.
    def __init__(self, curves: list[NXOpen.Curve])

class ClosedProfile:
    # Базовый класс замкнутых плоских профилей (многоугольников).
    def __init__(self, curves: list[NXOpen.Curve], vertices: list[tuple])
    def corner_point(self, index: int, offset: float)
        # Возвращает точку, смещённую на offset от вершины index

class Line:
    # Отрезок.
    def __init__(self, workPart, start, end)
    def on_frame(cls, workPart, frame, start_uv, end_uv)
        # Отрезок в плоскости frame, заданный ЛОКАЛЬНЫМИ (u, v)

class Circle:
    # Окружность.
    def __init__(self, workPart, radius, center=(0.0, 0.0), normal=(0.0, 0.0, 1.0))
    def on_frame(cls, workPart, radius, frame, u=0.0, v=0.0)

class Hide:
    # Скрывает двумерные кривые профилей.
    def __init__(self, session: NXOpen.Session, *profiles)

class Frame:
    # Локальная система координат в пространстве.
    def __init__(self, origin, u, v, normal=None)
    def point(self, u=0.0, v=0.0, w=0.0)
    def points(self, local_xy)

class Triangle:
    # Треугольник.
    def __init__(self, workPart, p1, p2, p3)
    def by_3_sides(cls, workPart, side_a, side_b, side_c, center=(0.0, 0.0), frame=None)
    def by_2_sides_and_angle(cls, workPart, side_a: float, side_b: float, angle_ab: float, center=(0.0, 0.0), frame=None)
    def by_2_angles_and_side(cls, workPart, angle_a: float, angle_b: float, side_ab: float, center=(0.0, 0.0), frame=None)

class Parallelogram:
    def __init__(self, workPart, side_a, side_b, angle, center=(0.0, 0.0), frame=None)

class Polygon:
    # Многоугольник по явным 3D-вершинам.
    def __init__(self, workPart, vertices: list)
    def on_frame(cls, workPart, frame, local_vertices)
