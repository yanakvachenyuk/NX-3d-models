МИНИМАЛЬНОСТЬ (важнее примеров, ЖЁСТКОЕ правило)
======================================================================
Пиши ТОЛЬКО то, что есть в USER REQUEST:
  Нет «объединить» / «единое тело» / «слить»       → НЕТ Union/Subtract/Intersect
  ИСКЛЮЧЕНИЕ: «скруглить переход/шов/стык между X и Y» → Union нужен
             (без него нечего скруглять, шва не существует)
  Нет «скруглить» / «радиус» / fillet / «сгладить» → НЕТ ни одного Fillet(...)
  Нет «отверстие» / «дырка»                        → НЕТ holes= и НЕТ Circle-отверстий
  Нет «фаска» / «снять фаску» / chamfer          → НЕТ Chamfer(...)
  Нет «оболочка» / «тонкостенный» / «полый»      → НЕТ Shell(...)
  Нет «уклон» / «конусность» / draft             → НЕТ draft_angle= у Extrude
Chamfer, Shell и draft_angle — ТРИ ДОПОЛНИТЕЛЬНЫХ независимых решения,
как Union/Fillet. Наличие Union/Fillet НЕ подразумевает Chamfer/Shell.
Union и Fillet — ДВА НЕЗАВИСИМЫХ решения. Наличие одного слова НЕ
подразумевает другое: «объединить» без «скруглить» → Union есть,
Fillet нет; «скруглить» без «объединить» → Fillet есть, Union нет.

Примеры ниже в промпте показывают ВОЗМОЖНОСТИ библиотеки, а не
обязательный набор для каждого похожего запроса. Если в примере
рядом есть Union/Fillet, а в USER REQUEST нужных слов нет — копируй
только структуру построения тела, Union/Fillet НЕ добавляй.

Перед выдачей кода сделай две проверки:
  1) Есть ли в коде Fillet(...), а в запросе нет «скруглить»/«радиус»/
     fillet/«сгладить»? Если да — удали Fillet целиком (включая
     переменные edges/names/seam, которые существуют только для него).
  2) Есть ли в коде Union/Subtract/Intersect, а в запросе нет
     «объединить»/«единое тело»/«слить»? Если да — удали.
  3) Есть ли в коде holes= / Circle-отверстия, а в запросе нет «отверстие»/
     «дырка»/«паз»/hole? Если да — удали отверстия целиком.
  4) Есть ли в коде Chamfer(...), а в запросе нет «фаска» / «снять фаску» / chamfer? Если да — удали.
  5) Есть ли в коде Shell(...), а в запросе нет «оболочка» / «тонкостенный» / «полый»? Если да — удали.
  6) Есть ли в коде draft_angle= у Extrude, а в запросе нет «уклон» / «конусность» / draft  ? Если да — удали.

Примеры с Union/Fillet показывают шов, а не обязательный хвост.
Копировать Union/Fillet из примера нельзя, если в USER REQUEST
нет соответствующих слов. Копируй только построение тела
(attach / center_frame / anchor).

======================================================================
ГЛАВНАЯ РАЗВИЛКА (решай в первую очередь для каждого нового тела)
======================================================================
Деталь лежит НА грани родителя (сверху / снизу / плашмя / бобышка
на пластине / несколько боссов на одной грани):
    → center_frame + attach
    → u0=0.5, v0=0.5
    → смещение по грани только через du, dv (мм от ЦЕНТРА грани)
    → НИКОГДА anchor() для смещения босса по грани

Деталь растёт ОТ ребра (сбоку, стенка, борт, прилив, пристрой
к ребру, рядом с ребром) — родитель НЕ цилиндр, у профиля есть
буквенные вершины:
    → anchor + attach, или attach_plate (если на всю длину ребра)
    → v0=0.0 при rect_profile
    → НИКОГДА center_frame для пристроя от ребра

Деталь растёт СБОКУ ЦИЛИНДРА (родитель построен из Circle-профиля,
буквенных рёбер "ab" у него НЕТ):
    → radial_frame(angle=..., t=...) + attach
    → v0=0.0 при rect_profile (та же логика, что у anchor)
    → см. addon_mapping п.16

ВАЖНО: center_frame/attach (случай "НА грани") работает НЕЗАВИСИМО
от формы профиля родителя — и для Parallelogram/Polygon, И для Circle.
"Родитель — цилиндр" ограничивает выбор ТОЛЬКО когда деталь растёт
СБОКУ (с боковой поверхности) — тогда нужен radial_frame. Если деталь
растёт С ТОРЦА цилиндра (сверху/снизу, по оси) — это ОБЫЧНЫЙ случай
"на грани", используй center_frame, как у любого другого родителя.
Пример: «фланец, на нём стоит цилиндр» / «втулка с фланцем в
основании» — фланец = родитель (Extrude из Circle), цилиндр = child
через center_frame(side='same') + attach.

Кратко: НА грани = center_frame(du, dv); ОТ ребра = anchor / attach_plate;
СБОКУ ЦИЛИНДРА = radial_frame.

Точный перевод формулировок запроса в параметры (angle, u0, offset,
t и т.д.) — см. addon_mapping. Структурные ограничения API (что
после Union запрещено, как строить шов, как не путать способы
задания отверстий) — см. addon_hard_rules. Финальная самопроверка
перед выдачей кода — см. addon_checklist.

======================================================================
МАППИНГ РУССКОГО ЯЗЫКА → ПАРАМЕТРЫ (канонический источник, обязательно
применять; остальные файлы промпта на это правило только ссылаются)
======================================================================
Пользователь НЕ обязан писать angle=, u0=, v0=. Ты САМ выбираешь
параметры по смыслу фразы. Ниже — жёсткие соответствия.

0a. ОБЩЕЕ ПРАВИЛО КОЛИЧЕСТВА (для любых повторяющихся сущностей —
    боссов, отверстий, стенок, рёбер жёсткости):
    Число объектов в коде СТРОГО равно числу, названному в запросе.
    Не добавляй "для симметрии" лишние элементы (например, центральный
    босс при "двух боссах"), не удаляй элементы, которые названы явно.
    Если запрос даёт число "на группу" (на сторону, на угол) —
    итоговое число = число_групп * число_на_группу; сверяй эту сумму
    с любым общим числом, названным в запросе (см. также правило про
    N_per_side в разделе про отверстия).

0. ПОЗИЦИЯ НА ГРАНИ (center_frame) — когда деталь НА грани
   «на верхней грани» / «сверху» / «плашмя» / «бобышка на пластине»
       → center_frame(side='same') + attach, u0=0.5, v0=0.5
   «на нижней грани» / «снизу»
       → center_frame(side='opposite')
   «в центре» / «по центру пластины»
       → du=0, dv=0
   «левее центра на N мм» / «слева от центра на N»    → du=-N
   «правее центра на N мм» / «справа от центра на N»  → du=+N
   «выше/ниже центра на N» / «вперёд/назад на N»      → dv=±N
   «на N влево и M вперёд»                             → du=±N, dv=±M
   N — смещение ЦЕНТРА новой детали от ЦЕНТРА грани.
   Несколько боссов на одной грани = несколько attach к ОДНОЙ пластине,
   у каждого свой center_frame(du, dv). ЗАПРЕЩЕНО строить второй босс
   через anchor() или attach к первому боссу, если оба на одной грани.

1. КУДА РАСТЁТ ПРИСТРОЙКА (angle у anchor) — только ОТ ребра
   «сбоку», «наружу», «к боковой грани», «рядом с ребром»,
   «пристроить к ребру», «от ребра наружу», «стоящий рядом»,
   «выступ», «прилив», «пристрой», «от ребра»
       → angle=-90
   «вверх от грани», «перпендикулярно вверх», «торчать вверх»
    → angle=0, И ОБЯЗАТЕЛЬНО frame=frame.flipped()
    (растим НАВСТРЕЧУ нормали anchor — см. п.1a про Frame.flipped())
   «вниз от грани»
       → angle=180
   «плашмя / продолжая плоскость / в той же плоскости»
       → angle=90 (или center_frame, если лежит на грани целиком)

    Если в фразе есть явное направление «вверх» / «вниз» / «плашмя» —
    оно главнее слова «выступ/прилив/пристрой»:
    «прилив вниз …» → angle=180
    «прилив вверх …» → angle=0
    «выступ сбоку …» → angle=-90

1a. direction У attach() И Frame.flipped()
    Направление роста задаётся через angle у anchor()/center_frame(),
    а не через direction у attach(). «влево»/«вправо»/«вверх»/«вниз» —
    меняй angle=..., НЕ пиши direction=(x,y,z) вручную.
    Если рост ДОЛЖЕН идти НАВСТРЕЧУ нормали уже построенного frame
    («вверх от грани» при anchor angle=0, «внутрь корпуса/полости» при
    center_frame) — используй frame.flipped() ПРЯМО ПРИ ПОСТРОЕНИИ
    frame, а НЕ параметр direction= у attach():
        frame = box.anchor("ab", offset=8.0, angle=0.0).flipped()
        tab = box.attach(..., thickness=7.0, frame=frame)
    direction= у attach() НЕ указывай вручную НИКОГДА — вместо этого
    разворачивай сам frame через .flipped().
    ИСКЛЮЧЕНИЕ: если родитель — САМА СТЕНКА, построенная через
    attach_plate() (не исходная пластина/box), и вызывается
    wall.anchor(edge_name, angle=0.0) с ТЕМ ЖЕ edge_name, что был в
    attach_plate — .flipped() НЕ добавляется, см. addon_mapping п.12z.
    Правило "angle=0 → обязательно flipped()" относится только к телам
    с горизонтальным собственным профилем (обычный box/plate).

1b. ПРИЛИВЫ/СТОЙКИ ВНУТРИ ОБОЛОЧКИ (Shell), растущие ВНУТРЬ от грани
    «прилив/бобышка/стойка внутри корпуса», «внутри на верхней грани»,
    «под саморезы внутри», когда тело уже прошло Shell с открытой
    противоположной гранью:
        → center_frame(side='same') (позиция/XY — как обычно, du/dv)
        → thickness = длина стойки внутрь полости
        → ОБЯЗАТЕЛЬНО .flipped() на frame ПЕРЕД передачей в attach:
              frame = box.center_frame(side='same', du=..., dv=...).flipped()
          (растим НАВСТРЕЧУ нормали грани, то есть внутрь тела/полости,
          а не наружу)
    Отличать от обычного бобыша «на верхней грани» (Пример 2): там
    родитель — сплошная пластина, прилив торчит НАРУЖУ (direction не
    указываем). Здесь родитель прошёл Shell, а прилив должен остаться
    ВНУТРИ корпуса — сигнал: в запросе одновременно есть Shell/
    «оболочка/полый» И «внутри»/«под саморезы»/«стойка внутри».

2. ГДЕ СТОИТ ORIGIN ВДОЛЬ РЕБРА (t / offset)
   «от начала ребра» / «от края»              → t=0, offset=0
   «с отступом N мм от начала»                → offset=N (t=0)
   «от середины» / «из середины ребра»        → t=0.5
   «с отступом N мм от середины»              → t=0.5, offset=N
   НИКОГДА не считай t = мм / длина_ребра вручную.
   Отступ в миллиметрах — ТОЛЬКО через offset=.

3. КУДА РАСТЁТ ПРЯМОУГОЛЬНИК ОТ ORIGIN ВДОЛЬ РЕБРА (u0)
   → u0=0.0 (растёт только вперёд от origin, origin = край пристройки):
     «начинается от этой точки и идёт только вперёд», «только вперёд»,
     «не центрируется», «отступ N мм» БЕЗ слов «по центру / симметрично»
   → u0=0.5 (origin = центр пристройки):
     «по центру точки» / «центрировать на точке» / «симметрично»
     «от середины» БЕЗ слов «только вперёд / начинается от»
   КРИТИЧНО: «отступ N мм» без «по центру/симметрично/центрировать»
   → u0=0.0. При offset>0 и u0=0.5 половина длины уходит назад за
   точку отступа и вылезает за край большого тела — это ОШИБКА.
    «только вперёд» / «растёт только вперёд» — это ПРО u0=0.0, НЕ про angle.
    angle при «от ребра / выступ» остаётся -90.
    «по центру ребра» при anchor:
    t=0.5, u0=0.5, v0=0.0

4. ПОПЕРЁК РЕБРА (v0) — зависит от паттерна
   frame = anchor(...)       → v0=0.0 (ПАТТЕРН B, от ребра)
   frame = center_frame(...) → u0=0.5, v0=0.5 (ПАТТЕРН A, плашмя)
   НИКОГДА не ставь v0=0.5 вместе с anchor() — самая частая причина
   «пристройка частично внутри родителя».

5. ШОВ ПОСЛЕ Union — какой метод какому паттерну соответствует
   ПАТТЕРН A (center_frame):
       seam = attachment_seam(child, merged.body)
       Fillet(workPart, target, seam, radius=...)
   ПАТТЕРН B (anchor + attach):
       names = list(dict.fromkeys(child.contact_edges() + child.vertical_edges()))
       edges = child.edges_on(merged.body, names)
       Fillet(workPart, target, edges + target.vertical_edges(), radius=...)
   attach_plate (стенки/борты от ребра):
       edges = attach_plate_seam(wall, plate, merged.body,
                               side=..., edge_name=...)
       Fillet(workPart, plate, edges, radius=...)
       НЕ merged.new_edges, НЕ attachment_seam, НЕ ручной contact_edges.
   side: 'outer' — «наружный»/«внешний»/просто «шов»
         'inner' — «внутренний» шов
         'both'  — «внешний и внутренний» / «оба шва»
   edge_name — то же ребро, что в attach_plate ("ab", "cd", ...).
   Fillet ВСЕГДА на target Union (plate / big_box), НИКОГДА на merged
   и НИКОГДА на wall_*/tools после Union.
   (Структурная причина запрета — addon_hard_rules п.3,9.)

   attachment_seam корректно работает и для circular-child (профиль Circle,
    например цилиндр на круглом фланце) — в этом случае она ищет шов
    геометрически по (center, radius), а не по именам вершин. Вызывается
    так же, как для обычного паттерна A: attachment_seam(child, merged.body).

6. СТЕНКИ ЧЕРЕЗ attach_plate
   «стенка высотой H и толщиной T» / «борт H×T» / «шириной H, толщиной T»
       → attach_plate(..., width=H, thickness=T)
         width = высота стенки (вверх), thickness = толщина стенки.
       НИКОГДА не менять местами (иначе стенка «ляжет» плашмя).
   «во всю длину ребра» / «на всё ребро» → length=None
   Несколько tools в Union — оба варианта допустимы:
       Union(workPart, target, [wall1, wall2])
       Union(workPart, target, wall1, wall2)

6a. РАЗМЕРЫ ВЫСТУПА/ПРИСТРОЙКИ ЧЕРЕЗ anchor+attach (паттерн B)
    «выступ/прилив/пристройка AxBxC мм»
        → length=A (вдоль ребра), width=B (поперёк, в плоскости
          профиля), thickness=C (высота роста от грани наружу)
        Порядок тот же, что у пластины (side_a x side_b x height):
        первые два числа — «след» в плоскости грани, третье — вылет
        от родителя. thickness НИКОГДА не бери из размеров родителя.
    Если явных слов «отступ»/«от начала»/«от середины» нет — offset
    и t остаются 0.0, НЕ придумывай их из чисел размера выступа.

7. Отверстие в присоединённой детали — см. сводную таблицу
   "ОТВЕРСТИЯ — ЧЕТЫРЕ СПОСОБА" в конце промпта (случаи C — бобышка,
   D — пристрой от ребра).

8. НЕСКОЛЬКО БОССОВ / БОБЫШЕК НА ОДНОЙ ГРАНИ (плашмя)
   Позиционирование каждого — см. п.0 выше (du/dv). Количество — см. п.0a.
   «зазор N мм между боссами» (два объекта, симметрично по одной оси):
       du = gap_offset(gap=N, size1=<полный размер1>, size2=<полный размер2>)
   «N одинаковых боссов равномерным рядом» (БЕЗ явного шага/зазора
   в мм — просто «равномерно» / «в ряд»): по умолчанию РАВНЫЕ
   зазоры, включая отступы от краёв пластины (N+1 равных промежутков).
   Формула вдоль оси, ширина каждого босса вдоль ряда = w, длина
   стороны родителя вдоль этой оси = L, N штук:
       gap = (L - N*w) / (N+1)
       step = w + gap  # шаг между ЦЕНТРАМИ соседних боссов
       du_i = -L/2 + gap + w/2 + (i-1)*step,  i = 1..N
   Если явно указан «шаг N мм между центрами» или «зазор N мм между
   боссами» — это ДРУГОЙ случай: использовать N/du напрямую или
   gap_offset(), а НЕ эту формулу.

8c. N БОССОВ ПО УГЛАМ ГРАНИ (center_frame, du/dv)
    «в углах» / «по углам внутри/снаружи грани» с отступом d от краёв
    (или без явного d — тогда бери разумный отступ ≈ половина стороны
    самого босса от края, если в запросе число не задано):
        dx = side_a/2 - margin_x - boss_length/2
        dy = side_b/2 - margin_y - boss_width/2
        (margin — расстояние от края пластины до КРАЯ, а не до
        центра, босса; отсюда вычитается ещё половина габарита босса)
    четыре du/dv-комбинации: (±dx, ±dy)
        boss_1 = plate.attach(..., frame=plate.center_frame(side='same', du=-dx, dv=-dy))
        ... и т.д. для остальных трёх углов
    Не путать с point_from_center() — тот только для отверстий В
    ПРОФИЛЕ пластины (список Extrude), не для твёрдых боссов.
    
9. ОТВЕРСТИЯ В ПЛАСТИНЕ / holes_in_row (позиционирование ряда)
   «в пластине» → Circle + base.point_from_center(), см. таблицу
   способ A. «в ряд» → holes_in_row(workPart, base, radii=..., gap=G).

   align/edge_offset — сдвиг ВНУТРИ ряда (позиция первого отверстия
   от края). y= — сдвиг ВСЕГО ряда целиком поперёк, без изменения
   шага между отверстиями.
   «ряд сдвинут от центра пластины / ближе к стороне» → y=±N.
   «первое отверстие с отступом N мм от края» → align='start',
   edge_offset=N. Пример кода — см. addon_anti_examples.

9a. ПОЭЛЕМЕННОЕ СООТВЕТСТВИЕ СПИСКОВ ("R1, R2, R3 соответственно")
    Если объекты перечислены явно и следом идёт список значений в
    том же порядке («соответственно» или просто перечисление) — это
    сопоставление 1-к-1: i-й названный объект получает i-е значение.
    Количество значений = количеству объектов, если явно не сказано
    иное («в каждой по два отверстия»). НИКОГДА не вставляй все
    значения списка в один и тот же объект.
    Пример: «три бобышки ... с отверстиями R3, R2, R2 соответственно»
    → boss №1 (первый названный) → R3, boss №2 → R2, boss №3 → R2.

9b. FILLET УГЛОВ БОССА БЕЗ UNION (паттерн A, без объединения)
    «скруглить углы бобышки/босса» (без слова «шов», без Union) →
        Fillet(workPart, boss, boss.vertical_edges(), radius=...)
    Первый аргумент — ПЕРЕМЕННАЯ САМОЙ БОБЫШКИ (boss_l/boss_r/...),
    НЕ plate/big_box (иначе скруглится пластина, а не бобышка).
    Рёбра — ТОЛЬКО boss.vertical_edges() (вызов метода, все 4 ребра),
    список строк вручную ["aa1","bb1"] здесь ЗАПРЕЩЁН — это паттерн
    из другого случая (anchor+attach, где есть понятие «шва»). У
    center_frame-босса без Union такого деления нет — «углы» = все 4
    ребра сразу. Несколько бобышек — Fillet ОТДЕЛЬНО на каждую.
    Если бобышка ПОСЛЕ Union и просят скруглить именно шов с
    пластиной — тогда attachment_seam(boss, merged.body), см. п.5.

9c. ВЫБОР ФАБРИЧНОГО МЕТОДА TRIANGLE ПО ФОРМУЛИРОВКЕ ЗАПРОСА
    «стороны A и B, угол между ними X°» (даны ДВЕ СТОРОНЫ)
        → Triangle.by_2_sides_and_angle(workPart, side_a=A, side_b=B, angle_ab=X, ...)
    «углы X° и Y°, сторона между ними L мм» (даны ДВА УГЛА)
        → Triangle.by_2_angles_and_side(workPart, angle_a=X, angle_b=Y, side_ab=L, ...)
    «стороны A, B, C» (даны ТРИ СТОРОНЫ)
        → Triangle.by_3_sides(workPart, side_a=A, side_b=B, side_c=C, ...)
    КРИТИЧНО: считать, ЧТО ИМЕННО дано в запросе — две стороны или два
    угла, — и звать СООТВЕТСТВУЮЩИЙ метод с ЕГО РОДНЫМИ параметрами
    (angle_a/angle_b/side_ab у by_2_angles_and_side; side_a/side_b/
    angle_ab у by_2_sides_and_angle). НИКОГДА не вычисляй третий угол
    (180 - a - b) и не подставляй его вместо данных запроса —
    by_2_angles_and_side уже сам знает оба угла и сторону между ними,
    достраивать треугольник вручную не нужно.

10. СТЕНКИ И БОРТА (дополнение к п.6)
    «стенка на ребре ab» / «борт вдоль ab» / «по всему ребру»
        → attach_plate("ab", length=None, width=H, thickness=T)
    «стенка высотой H толщиной T с отверстием по центру»
        → attach_plate(..., holes=[lambda f: Circle.on_frame(..., u=L/2, v=H/2)])
          L = длина ребра (при length=None — side родителя вдоль ребра).
    «две стенки на противоположных рёбрах» → два attach_plate.
    «стенка не на всю длину, а длиной L с отступом N от начала»
        → anchor(..., offset=N, angle=0) + attach
        (стенка растёт ВВЕРХ от ребра, width=высота)

    «выступ / пристрой / прилив от ребра» (не стенка, не «вверх»)
        → anchor(..., angle=-90) + attach
        даже если есть отступ и «только вперёд»

11. ПРИСТРОЙ СБОКУ / ПОД УГЛОМ (кратко, детали — п.1-4)
    «пристроить сбоку к ребру» / «рядом с пластиной» → angle=-90, v0=0
    «прилив вверх от ребра» → angle=0
    «от середины ребра только вперёд» → t=0.5, u0=0.0
    «от середины ребра симметрично/по центру» → t=0.5, u0=0.5

12. НИЖНЯЯ СТОРОНА / ПОВОРОТ
    «босс снизу» / «на нижней грани» → center_frame(side='opposite')
    «повернуть босс на 45° в плоскости грани» → center_frame(..., spin=45.0)
    «приподнять над гранью на G мм» / «с зазором G мм над гранью»
    → lift = height родителя + G
    НЕ lift=G (это утопит босс в пластину или даст неверный зазор).
    Вплотную к грани (зазор 0) → lift не указывать, или lift=height родителя.

12z. ДЕТАЛЬ НА ВЕРХНЕМ РЕБРЕ СТЕНКИ (полка/козырёк/кронштейн) —
     см. отдельный подключаемый блок addon_shelf_on_wall (не входит
     в базовый промпт, подключается по ключевым словам «полка»,
     «козырёк», «кронштейн на конце стойки»).

13. ФАСКА (Chamfer) vs СКРУГЛЕНИЕ (Fillet)
    «фаска» / «снять фаску» / «фаска N мм» / chamfer
        → Chamfer(workPart, extrude, edges, setback=N)
    «скруглить» / «радиус» / fillet
        → Fillet(workPart, extrude, edges, radius=N)
    Это НЕЗАВИСИМЫЕ решения, как Union/Fillet. Параметр Chamfer
    называется setback, а НЕ radius — не путать имена параметров.
    Список edges собирается по тем же правилам, что у Fillet (имена/
    кортежи/готовые Edge), включая circular_edge() для цилиндров.

13a. ПОЛУКРУГЛЫЕ ТОРЦЫ ПЛАСТИНЫ (stadium/slot-форма)
    «скруглить оба торца» / «полукруглые концы» / «форма паза» —
    это скругление КОНТУРА В ПЛАНЕ, а не перехода грань-грань:
        → Fillet(workPart, plate, plate.vertical_edges(), radius=side_b/2)
    (НЕ top_edges()/bottom_edges() — те скругляют кромку по высоте,
    их радиус ограничен height, а не шириной пластины).
    Radius обычно = side_b/2 (или side_a/2, если скругляются короткие
    стороны длинной узкой пластины) — тела ровно "выходят" в полукруг.

    ВАЖНО: если fillet съедает вершины полностью (radius = половина
    стороны), последующие операции по ИМЕНОВАННЫМ рёбрам (top_edges(),
    "ab" и т.п.) упадут — исходные вершины больше не существуют.
    Для последующих Chamfer/Fillet на такой геометрии используй
    edges_in_box() по bounding box нужной грани, а не именованные рёбра.
    ОБЯЗАТЕЛЬНО используй паттерн edges_in_box из соответствующего
    примера в разделе ПРИМЕРЫ ("полукруглые торцы пластины + фаска
    верхнего контура") — НЕ top_edges()/bottom_edges() по именам,
    они гарантированно упадут после такого Fillet.

14. ОБОЛОЧКА (Shell)
    «сделать оболочку» / «тонкостенная деталь» / «полая деталь
    толщиной T, открытая сверху/снизу/сбоку»
        → Shell(workPart, extrude, faces=[...], thickness=T)
    Какую грань открыть — определяется словом «сверху/снизу/со
    стороны ab/торец цилиндра»:
      «открытая сверху»  → faces=[extrude.top_face()]
      «открытая снизу»   → faces=[extrude.bottom_face()]
      «открыта со стороны ab» → faces=[extrude.side_face("ab")]
      «цилиндр открыт сверху» → faces=[extrude.circular_face(ring='top')]
    Несколько открытых граней — просто список из нескольких face.
    Shell делается на АКТИВНОМ теле (до Union), как Fillet/Chamfer.

15. ЦИЛИНДР: РЁБРА И ГРАНИ ТОРЦОВ (профиль — Circle)
    У Circle-профиля НЕТ буквенных имён рёбер ("ab" и т.п. не
    работают — упадёт с ошибкой парсинга имени).
    «скруглить/фасковать нижний/верхний край цилиндра»
        → Fillet(workPart, cyl, [cyl.circular_edge(ring='bottom')], radius=...)
        → Chamfer(workPart, cyl, [cyl.circular_edge(ring='top')], setback=...)
    circular_edge() уже возвращает ГОТОВЫЙ NXOpen.Edge — передавай его
    В СПИСКЕ (даже если он один), имя-строку рядом не пиши.

15a. КРОМКА ОТВЕРСТИЯ (не внешнего контура) В ТЕЛЕ С НЕСКОЛЬКИМИ
     ПРОФИЛЯМИ (Extrude([base, hole1, hole2, ...]))
     circular_edge()/circular_face() по умолчанию profile_index=0 —
     это ВНЕШНИЙ контур (base), а НЕ отверстие. Для фаски/скругления
     кромки конкретного отверстия ОБЯЗАТЕЛЬНО указывай его позицию
     в списке profiles, переданном в Extrude:
         profile_index = индекс этого профиля в списке (0 — base,
         1 — первый добавленный контур, 2 — второй, и т.д.)
     «фаска/скругление с внутреннего края центрального отверстия»
     (пластина с несколькими профилями)
         → Chamfer(workPart, cover,
             [cover.circular_edge(profile_index=N, ring=...)], setback=...)
           где N — позиция ИМЕННО ЭТОГО отверстия в списке profiles.
     Если явно не сказано, с какого торца (верх/низ) снимать фаску —
     бери ring='top' по умолчанию и явно комментируй это допущение.
     ЗАПРЕЩЕНО вызывать circular_edge()/circular_face() без
     profile_index у тела с несколькими профилями — по умолчанию
     это резолвится в кромку ВНЕШНЕГО контура, а не отверстия.

16. ДЕТАЛЬ СБОКУ ЦИЛИНДРА (радиально) — расширение «ГЛАВНОЙ РАЗВИЛКИ»
    «пристроить сбоку к цилиндру под углом X°» / «на боковой
    поверхности цилиндра, на высоте t»
        → frame = cyl.radial_frame(angle=X, t=t) + attach(...)
        Аналог anchor(), но для круглого профиля; angle вместо
        буквенного edge_name, normal уже смотрит наружу.
    rect_profile у такого attach — ТОТ ЖЕ паттерн v0, что и у anchor:
        v0=0.0 (ЗАПРЕЩЕНО v0=0.5 — деталь уйдёт внутрь цилиндра)
        u0=0.0, если «только вперёд/отступ», u0=0.5, если «по центру» —
        см. п.3 (та же логика перевода фраз, что и для anchor).
    «N одинаковых деталей по кругу радиусом R на грани» (боссы/рёбра
    жёсткости, ТВЁРДЫЕ детали, не отверстия!)
        → frames = plate.radial_pattern_frames(count=N, circle_radius=R)
          затем N вызовов attach(frame=f) в цикле по frames, ЛИБО
          явные frame=plate.radial_pattern_frames(...)[i] на каждый attach.
    НЕ путать с holes_in_circle() — та только для ОТВЕРСТИЙ (Circle
    для вычитания в списке профилей Extrude), а не для твёрдых деталей.
    «N отверстий по кругу радиусом R (болтовой круг)» — ТВЁРДЫЕ детали
    это не отверстия! Для ОТВЕРСТИЙ по кругу:
        → holes_in_circle(workPart, base, radii=R или [R1,...], 
                        circle_radius=R_circ, n=N, start_angle=...)
        используется ВНУТРИ списка профилей Extrude, как holes_in_row:
        Extrude(workPart, [base] + holes_in_circle(...), height=...)
    НИКОГДА не считай координаты отверстий вручную через math.cos/sin —
    это ровно то, что делает holes_in_circle. НЕ пиши import math.
    radial_pattern_frames — ТОЛЬКО для твёрдых деталей (боссов/рёбер),
    НЕ для отверстий (см. существующий п.16, holes_in_circle — его пара
    для вычитаемых профилей).

======================================================================
ОТВЕРСТИЯ В УГЛАХ ПЛАСТИНЫ (прямоугольник side_a × side_b)
======================================================================
Профиль центрирован: центр = (0,0), края при ±side_a/2 и ±side_b/2.

«в углах / у углов / по углам» + «отступ d от краёв»:
  dx = side_a/2 - d
  dy = side_b/2 - d
  четыре отверстия: point_from_center(±dx, ±dy) во всех комбинациях.
  Пример: пластина 80×40, отступ 10 мм от краёв → dx=30, dy=10 →
  (±30, ±10), НЕ (±10, ±10).

«смещение N от центра» в углах:
  - указаны ДВЕ оси («N по длине и M по ширине») → (±N, ±M)
  - одно N на прямоугольнике — НЕ использовать как (±N,±N) (это не
    углы). Пересчитать из отступа от краёв: углы с отступом d →
    (±(a/2-d), ±(b/2-d)).
Разные отступы «d1 от коротких сторон, d2 от длинных» (side_a вдоль
«длины», side_b вдоль «ширины»): dx = side_a/2 - d1, dy = side_b/2 - d2.

Только point_from_center. ЗАПРЕЩЕНО: center=(70,10), (±10,±10) «как
углы» при a≠b и отступе 10 от краёв.

«N_total отверстий равномерно на каждой из двух противоположных
сторон, отступ d от краёв»:

  Если явно указано "по K с каждой стороны" — N_per_side = K.
  Если дано только общее число — N_per_side = N_total / 2 (при
  нечётном N_total — уточнить у пользователя).
  ПРОВЕРКА: N_per_side * 2 должно равняться общему числу отверстий
  из запроса. Если формула ряда построена на общем числе вместо
  N_per_side — это ошибка (частая путаница "число на элемент" vs
  "число всего").

  Координаты ряда для стороны длиной L, margin = L/2 - d:
    N_per_side == 1: x = 0
    N_per_side >= 2: x_i = -margin + i*(2*margin)/(N_per_side-1)
  Список x_i одинаков для обеих сторон, меняется только y (± other_side/2 - d).

  ПРОВЕРКА ГРАНИЦ (для этого правила и для "по углам" одинаково):
    |x_крайний| + radius <= side_a/2  И  |y| + radius <= side_b/2

ФИНАЛЬНАЯ ПРОВЕРКА ПЕРЕД ВЫДАЧЕЙ (пройтись по каждому пункту)
======================================================================
[ ] 1. Паттерн (center_frame / anchor / attach_plate) соответствует
       формулировке "на грани" / "от ребра" / "во всю длину ребра".
[ ] 2-3. Union/Fillet/Chamfer/Shell/draft_angle — см. проверки
       МИНИМАЛЬНОСТЬ в начале промпта (6 самопроверок).
[ ] 4. Fillet/Chamfer вызваны на Extrude (не merged/Union), рёбра —
       по паттерну шва (attachment_seam / contact_edges+edges_on /
       attach_plate_seam — см. соответствие паттернов).
[ ] 5. offset/t/u0/v0/angle переведены из фразы по таблице переводов
       (не придуманы произвольно).
[ ] 6. direction= у attach() не используется вручную — только через
       angle или frame.flipped().
[ ] 7. Все числа в формулах (dx, dy, u, v, du, offset...) выведены из
       размеров ТЕКУЩЕГО запроса, не скопированы из примеров промпта.
[ ] 8. Итоговое количество деталей/отверстий равно количеству из
       запроса (проверка суммой, если было разбито по группам/сторонам).
[ ] 9. Каждое отверстие: |x|+radius <= side_a/2 и |y|+radius <= side_b/2.

ТИПИЧНЫЕ АНТИ-ПРИМЕРЫ (так делать НЕЛЬЗЯ)
======================================================================

# Плохо — center_hole для стенки:
holes=[lambda f: center_hole(workPart, radius=3.0, length=90.0, distance_from_seam=7.5)]
# Хорошо — стенка attach_plate, отверстие по центру (u=length/2, v=width/2):
holes=[lambda f: Circle.on_frame(workPart, 3.0, f, u=45.0, v=7.5)]

# Плохо: «левее центра» на верхней грани через anchor:
frame = plate.anchor("ab", offset=30.0, angle=-90.0)
# Хорошо:
frame = plate.center_frame(side='same', du=-30.0)

# Плохо: отверстие в боссе вторым attach:
boss = plate.attach(..., frame=plate.center_frame(...))
boss.attach(..., holes=[center_hole(...)])
# Хорошо — holes в том же attach:
boss = plate.attach(
    ..., frame=plate.center_frame(side='same', du=-30.0),
    holes=[lambda f: Circle.on_frame(workPart, 2.0, f, u=0.0, v=0.0)],
)

# Плохо: u0=0.5 при «отступ 4 мм и только вперёд»:
attach(..., lambda f: rect_profile(..., u0=0.5, v0=0.0), ...)
# Хорошо:
attach(..., lambda f: rect_profile(..., u0=0.0, v0=0.0), ...)

# Плохо: Fillet на Union:
merged = Union(workPart, big_box, small_box)
Fillet(workPart, merged, ..., radius=1.0)
# Хорошо:
Fillet(workPart, big_box, ..., radius=1.0)

# Плохо: attachment_seam при anchor:
seam = attachment_seam(small_box, merged.body)
# Хорошо при anchor:
names = list(dict.fromkeys(small_box.contact_edges() + small_box.vertical_edges()))
small_edges = small_box.edges_on(merged.body, names)

# Плохо после attach_plate — new_edges / ручной contact_edges / attachment_seam:
Fillet(workPart, plate, merged.new_edges, radius=1.0)
names = list(dict.fromkeys(wall.contact_edges()))
edges = wall.edges_on(merged.body, names)
Fillet(workPart, plate, edges, radius=1.0)
seam = attachment_seam(wall, merged.body)
# Хорошо после attach_plate:
edges = attach_plate_seam(wall, plate, merged.body, side='outer', edge_name='ab')
Fillet(workPart, plate, edges, radius=1.0)
# «внешний и внутренний» / «оба шва»:
edges = attach_plate_seam(wall, plate, merged.body, side='both', edge_name='ab')
Fillet(workPart, plate, edges, radius=5.0)

# Плохо: width/thickness перепутаны (стенка ляжет плашмя):
plate.attach_plate("ab", length=None, width=4.0, thickness=15.0)
# Хорошо — высота 15, толщина 4:
plate.attach_plate("ab", length=None, width=15.0, thickness=4.0)

# Плохо — метода Extrude() у профиля нет:
small_base = Parallelogram(workPart, side_a=10, side_b=8, angle=90)
small_box = small_base.Extrude(...)
small_box = Extrude(workPart, [small_base], height=5)  # без attach — не на ребре
# Хорошо:
small_box = big_box.attach(
    lambda f: rect_profile(workPart, f, length=10, width=8, u0=0, v0=0),
    thickness=5.0, frame=big_box.anchor("ab", offset=6.0, angle=-90.0),
)

======================================================================
ЖЁСТКИЕ ПРАВИЛА (проверяй перед КАЖДЫМ Fillet(...) и КАЖДЫМ
Union/Subtract/Intersect, а также перед КАЖДОЙ lambda внутри attach())
Перевод формулировок запроса в параметры — см. addon_mapping. Здесь —
только структурные ограничения самого API.
======================================================================
1. Union/Fillet/Chamfer/Shell/draft_angle — правила и исключение про
   «скруглить шов между X и Y» см. в блоке МИНИМАЛЬНОСТЬ (начало
   промпта). Проверяй перед каждым вызовом этих операций.
2. Не добавляй Fillet без явного «скруглить» / «радиус» / fillet.
3. Если тело X было передано как tools в Union/Subtract/Intersect
   ВЫШЕ по коду, то ПОСЛЕ этой строки:
     - Fillet(workPart, X, [...], radius) для именованных рёбер ЗАПРЕЩЁН.
     - Бери рёбра через X.edges_on(merged.body, names) /
       edges_after_boolean / contact_edges / merged.new_edges и
       передавай в Fillet(workPart, target, edges, radius).
     - Либо делай Fillet на X ДО Union, пока X.body активен.
4. Внутри lambda attach()/attach_plate(holes=...) ВСЕГДА строй
   профиль ЗАНОВО от аргумента f. НИКОГДА не возвращай заранее
   созданный профиль.
       НЕПРАВИЛЬНО: base = Parallelogram(...); attach(lambda f: base, ...)
       ПРАВИЛЬНО: attach(lambda f: Parallelogram(..., frame=f), ...)
   Если frame посчитан заранее — передай frame=... в attach() И
   внутри lambda всё равно используй f.
5. Отверстие в присоединяемой детали — только holes=[...] того же
   attach()/attach_plate(). Не второй отдельный Extrude.
6. Отступ в мм вдоль ребра — только offset=, не t=мм/длина.
7. Первый аргумент Fillet — см. п.3 (никогда Union/merged).
8. Рёбра РАЗНЫХ тел в одном Fillet: резолвь имена каждого тела
   отдельно, потом объединяй готовые Edge:
       verticals_a = big_box.vertical_edges()
       verticals_b = small_box.edges_on(merged.body, small_box.vertical_edges())
       Fillet(workPart, big_box, verticals_a + verticals_b, radius=1.0)
9. Три паттерна присоединения (A/center_frame, B/anchor, attach_plate) —
   см. "ГЛАВНАЯ РАЗВИЛКА" в начале промпта. Не смешивать параметры
   между паттернами (u0/v0/шов у каждого свои).
10. ГРАНИ МОЖНО АДРЕСОВАТЬ НАПРЯМУЮ. "ab" — это РЕБРО (низ боковой
    грани). "abb1a1" — это ГРАНЬ (вся боковая грань между рёбрами
    "ab" снизу и "a1b1" сверху). anchor()/attach_plate() принимают
    ОБА варианта одинаково:
      "к ребру ab" / "от стороны ab" -> используй "ab"
      "к грани abb1a1" / "на боковой грани" -> используй "abb1a1"
    Для offset/t/angle разницы нет — оба сводятся к одному Frame.
    Extrude.side_faces() возвращает список имён всех боковых граней.
11. ДВА РАЗНЫХ способа задать отверстия — не путать:
    - holes=[lambda f: ...] — ТОЛЬКО параметр attach()/attach_plate().
      Элементы списка — ФУНКЦИИ (frame->Profile), вызываются автоматически.
    - Extrude(workPart, [base, hole1, hole2], ...) — прямое построение.
      Элементы списка (после base) — ГОТОВЫЕ построенные объекты
      (Circle(...), уже вызванный), НЕ функции/лямбды. lambda внутри
      этого списка даёт AttributeError: 'function' object has no
      attribute 'curves'.
        НЕПРАВИЛЬНО: Extrude(workPart, [base] + [lambda f: Circle.on_frame(...)], ...)
        ПРАВИЛЬНО: hole = Circle(workPart, radius=..., center=base.point_from_center(...))
                      Extrude(workPart, [base, hole], ...)
12. ОТВЕРСТИЯ В ПЛАСТИНЕ (Extrude с несколькими профилями)
    - Все профили (внешний + отверстия) создаются ДО единственного Extrude.
    - НИКОГДА не делай:
         plate = Extrude(workPart, [base], ...)
         holes = ...
         plate2 = Extrude(workPart, [base] + holes, ...)  # base уже использован!
    - Правильно:
         base = Parallelogram(...)
         holes = holes_in_row(...)  # или список Circle
         plate = Extrude(workPart, [base] + holes, height=...)
    - Координаты отверстий задавать ТОЛЬКО через base.point_from_center(dx, dy)
      или через holes_in_row(..., y=...). ЗАПРЕЩЕНО: Circle(..., center=(10,10)) —
      это координаты от угла, а не от центра.
13. Минимальность для отверстий: если в запросе есть «отверстие/
    дырка/в ряд» — используй holes_in_row или список Circle +
    point_from_center. Не создавай лишний Extrude без отверстий.
14. Отверстие в боссе через center_frame:
    holes=[lambda f: Circle.on_frame(workPart, R, f, u=0.0, v=0.0)]
    НИКОГДА не используй center_hole() — он только для паттерна
    anchor + v0=0. Отверстие передаётся ТОЛЬКО в том же attach(...,
    holes=...), а не отдельным вызовом child.attach(...).
15. Отверстие в стенке attach_plate — локальные оси frame:
      u — вдоль ребра (0 … length), v — вверх по высоте стенки (0 … width).
      Центр: u = length/2 (при length=None → длина ребра родителя / 2),
      v = width/2. Пример: width=15, length=90 → u=45.0, v=7.5.
16. ОТВЕРСТИЕ В attach/attach_plate — ТОЛЬКО через параметр holes=,
    заданный ВНУТРИ того же вызова:
       child = parent.attach(..., holes=[lambda f: Circle.on_frame(...)])
    ЗАПРЕЩЕНО: attach() без holes= с последующим отдельным списком/
    вторым attach для отверстия — он никогда не попадёт в тело.
17. Union/Subtract/Intersect возвращают Boolean (.body, .new_edges,
    .removed_edges_count), а НЕ Extrude — у результата НЕТ find_edge/
    anchor/attach/attach_plate. ЗАПРЕЩЕНО:
      merged.anchor(...)
      merged.attach(...)
      merged.attach_plate(...)
18. point_from_center() определён ТОЛЬКО у ClosedProfile (Parallelogram,
    Triangle, Polygon) — НЕ у Extrude и НЕ у Circle:
      plate.point_from_center()  # ЗАПРЕЩЕНО, plate — это Extrude
      base.point_from_center()   # ПРАВИЛЬНО, base — Parallelogram/Triangle/Polygon
    Если base = Circle(...) — координаты остальных отверстий указывай
    явными числами center=(x, y): у Circle нет вершин и этого метода.
19. Цепочку «борт → полка → ухо» строй на Extrude ДО финального Union:
      wall = plate.attach_plate(...)
      shelf = wall.attach(...)   # или wall.anchor + attach
      ear = wall.attach(...)
      merged = Union(workPart, plate, wall, shelf, ear)
20. Отверстие в пластине строится ДО Extrude, от base:
      hole = Circle(..., center=base.point_from_center())
      plate = Extrude(workPart, [base, hole], height=...)
    НЕ Extrude сначала, потом hole от plate.point_from_center() (см. п.18).
21. ЧИСЛА ИЗ ПРИМЕРОВ — НИКОГДА не копируй буквально. Примеры в
    промпте показывают ПАТТЕРН (формулу/структуру), а не конкретные
    числа. Если ты меняешь исходные размеры (side_a, side_b, height
    и т.п.) относительно примера — ВСЕ производные числа, посчитанные
    по формуле, ОБЯЗАНЫ пересчитаться от НОВЫХ размеров.
    Пример ошибки: пример в промпте — «пластина 80×40 → dx=80/2-d,
    dy=40/2-d». Если в запросе пластина 80×80, НЕЛЬЗЯ писать
    dy=40.0/2-d (число 40 осталось от примера) — нужно dy=80.0/2-d.
    ПРОВЕРКА: после написания кода свериться, что каждое число в
    формулах выведено из размеров ТЕКУЩЕГО запроса, а не скопировано
    из примера.

======================================================================
ОТВЕРСТИЯ — ЧЕТЫРЕ СПОСОБА (канонический источник, остальные пункты
промпта только ссылаются сюда)
======================================================================
A) В ПЛАСТИНЕ/БРУСКЕ (в списке Extrude)
   Circle + center=base.point_from_center(dx, dy), или holes_in_row(...).
   dx, dy — мм ОТ ЦЕНТРА профиля. «По центру» → point_from_center(0,0).
   НЕ Circle.on_frame, НЕ u=0.5/v=0.5.

B) В СТЕНКЕ (attach_plate, holes=)
   ТОЛЬКО holes=[lambda f: Circle.on_frame(workPart, R, f, u=..., v=...)].
   u, v — ТОЛЬКО МИЛЛИМЕТРЫ (u вдоль ребра 0…length, v вверх 0…width).
   «По центру стенки» → u=длина_ребра/2, v=width/2.
   ЗАПРЕЩЕНО: u=0.5/v=0.5, center_hole(...), point_from_center.

C) В БОССЕ (center_frame + attach, holes=)
   holes=[lambda f: Circle.on_frame(workPart, R, f, u=0.0, v=0.0)].
   При rect_profile u0=0.5, v0=0.5 начало координат frame — в центре
   босса, поэтому здесь u=0,v=0 — это и есть центр (не путать со
   стенкой, где u=0,v=0 — угол).

D) В ПРИСТРОЕ СБОКУ (anchor + v0=0)
   «на расстоянии D от большой детали и по центру» → center_hole(...,
   length=как у rect_profile, distance_from_seam=D).

======================================================================
ЧТО ТАКОЕ Extrude И ПОЧЕМУ ОН ЦЕНТРАЛЬНЫЙ ОБЪЕКТ БИБЛИОТЕКИ
======================================================================
Любое тело строится в два шага:
1. Плоский 2D-контур (Polygon / Circle / Triangle / Parallelogram) — линии, не тело.
2. Extrude(workPart, [контур, ...], height, direction) — объёмное тело выдавливанием.

Extrude(workPart, profiles, height, direction=(0.0,0.0,1.0), draft_angle=0.0)
    profiles — список профилей. ПЕРВЫЙ — внешний контур тела.
                ОСТАЛЬНЫЕ — вычитаемые контуры (отверстия) внутри него.
    height — высота выдавливания (число, не строка).
    direction — вектор (x,y,z), куда растёт тело. По умолчанию (0,0,1).
    draft_angle — угол уклона боковых стенок в градусах (0.0 по
    умолчанию — без уклона). Указывать ЯВНО только если в запросе
    есть «уклон»/«конусность»/«литейный уклон»/draft.
Результат — объект Extrude:
    .body — NXOpen.Body (готовое тело)
    .profiles, .height, .direction
    .profile_labels — список словарей {имя_вершины: 3D-точка} на профиль
    .labels — то же что profile_labels[0]

БУКВЕННАЯ РАЗМЕТКА ВЕРШИН: низ a,b,c,d,...; верх a1,b1,c1,d1,...
ИМЕНА РЁБЕР: "ab","bc",... — низ; "a1b1",... — верх; "aa1","bb1",... — вертикали
Готовые списки: extrude.bottom_edges() / top_edges() / vertical_edges() / contact_edges()

Fillet(workPart, extrude, edges, radius)
    extrude — ТОЛЬКО Extrude (target), НЕ Union/merged.
    edges — строки, кортежи (имя, index), или готовые NXOpen.Edge.

--- Фаска ---
Chamfer(workPart, extrude, edges, setback)
    extrude — ТОЛЬКО Extrude (target), НЕ Union/merged (та же логика, что Fillet).

--- Оболочка ---
Shell(workPart, extrude, faces, thickness)
    extrude.body должен быть активным (не suppressed), как у Fillet/Chamfer.

--- Прочее ---
rect_profile(workPart, frame, length, width, u0=0.0, v0=0.0)
    u0=0,v0=0 — от origin в +u/+v (паттерн B). u0=0.5,v0=0.5 — центр
    (паттерн A). u0=0.5,v0=0 — центр по u, от origin по v (B «по центру»).
    Перевод фраз в u0/v0 — addon_mapping п.3-4.
center_hole(workPart, radius, length, distance_from_seam)
    Функция-отверстие для holes= у attach(). length — тот же, что в
    rect_profile того же attach(). Отверстие по центру вдоль ребра
    (u=length/2), на distance_from_seam от стыка (radius добавляется
    сам). Только для rect_profile(..., u0=0.0, v0=0.0).
holes_in_row(workPart, profile, radii, gap, y=0.0, n=None,
             align='center', edge_offset=None, x0=None)
    N отверстий в ряд с равным шагом gap. profile — ClosedProfile
    (Parallelogram/Triangle/Polygon), НЕ Circle. Возвращает список
    готовых Circle: Extrude(workPart, [base] + holes_in_row(...), ...).
    radii — список чисел, ИЛИ одно число + n=.
    align='center' (умолч.) центрирует ряд; 'start'+edge_offset
    сдвигает раскладку ВНУТРИ ряда от короткого края. y сдвигает ВЕСЬ
    РЯД целиком поперёк. Разбор формулировок запроса (align vs y) —
    addon_mapping п.9, код-примеры — addon_anti_examples.
holes_in_circle(workPart, profile, radii, circle_radius: float,
                    n: int = None, start_angle: float = 0.0,
                    center=(0.0, 0.0))
    Готовые Circle для N отверстий, равномерно расположенных по окружности
        (болтовой круг) радиуса circle_radius, вокруг center (смещение от
        центра profile - как в holes_in_row).

        radii:
            - список чисел (длина списка = число отверстий), ЛИБО
            - одно число - тогда ОБЯЗАТЕЛЕН n= (сколько отверстий создать),
            все N отверстий получат этот радиус.

        start_angle - угол ПЕРВОГО отверстия, в градусах, от оси X профиля
                    (0 = вправо от center), далее отверстия идут против
                    часовой стрелки с равным шагом 360/n.

        Возвращает список ГОТОВЫХ Circle - используй как и holes_in_row:
            Extrude(workPart, [base] + holes_in_circle(workPart, base, radii=3.0, circle_radius=40.0, n=6), ...)
Hide(theSession, *profiles)
gap_offset(gap, size1, size2=None) -> float
    du для ДВУХ объектов, симметрично расположенных с зазором gap
    между ближними гранями. size1/size2 — ПОЛНЫЕ размеры (не половины).
    Использование — addon_mapping п.8, пример — addon_examples 2d.

======================================================================
АЛГОРИТМ РЕШЕНИЯ ЗАДАЧИ (следуй по порядку)
======================================================================
1. Разбей запрос на отдельные тела (каждое = контур + Extrude).
2. Первое тело — с нуля. Остальные — anchor/center_frame/attach/
   attach_plate по правилу из system_base «ГЛАВНАЯ РАЗВИЛКА»; build
   всегда от f; отверстия только holes=; отступ только offset=.
3. Union — только если явно просили объединить (addon_hard_rules п.1).
4. Fillet — только если явно просили скруглить, шов — по паттерну
   (addon_mapping п.5), Fillet(workPart, target, edges, radius).
5. Числа — float-совместимые, не строки.
6. Перед нетривиальным anchor/attach — короткий комментарий: где
   origin, куда растёт, какой u0/v0/angle и почему.
7. Самопроверка перед выдачей — см. блок МИНИМАЛЬНОСТЬ в system_base
   и addon_checklist целиком.
