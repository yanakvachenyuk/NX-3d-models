======================================================================
ОБЯЗАТЕЛЬНЫЙ ЧЕК-ЛИСТ ПЕРЕД КАЖДЫМ Fillet / Union / attach
======================================================================
Быстрая сверка перед выдачей кода. Если правило непонятно почему —
объяснение и примеры в addon_mapping / addon_hard_rules, здесь только
факт для финальной проверки. Если хотя бы один пункт не выполнен —
перепиши код до выдачи ответа.

[ ] 0. Деталь НА грани или ОТ ребра? НА грани → center_frame (du/dv);
       ОТ ребра → anchor/attach_plate. «Левее/правее центра» на грани
       → du, НЕ anchor.
[ ] 1. Первый аргумент Fillet — Extrude (big_box/plate/boss/...), НЕ
       merged/merged.body и НЕ wall_*/tools после Union.
[ ] 2. Тело, бывшее tools в Union, уже suppressed — его рёбра берутся
       ТОЛЬКО через edges_on/edges_after_boolean/contact_edges/
       new_edges, никогда напрямую именованными строками.
[ ] 3. Паттерн шва совпадает с паттерном присоединения (center_frame→
       attachment_seam; anchor→contact_edges+edges_on; attach_plate→
       attach_plate_seam). Не путать паттерны.
[ ] 4. «Только вперёд/отступ N без «по центру»» → u0=0.0. «По центру/
       симметрично» → u0=0.5.
[ ] 5. «Сбоку / наружу / к ребру / выступ / пристрой / от ребра» без явного
       «вверх от грани» → angle=-90. «Только вперёд» на angle НЕ влияет (это u0).
[ ] 5a. direction= у attach() указан без явной необходимости? Убери —
        направление меняется через angle, не вручную.
[ ] 6. Union с 2+ tools: список ИЛИ несколько аргументов — оба ок.
[ ] 7. После attach_plate + Union — ТОЛЬКО attach_plate_seam(...),
       НЕ merged.new_edges, НЕ attachment_seam.
[ ] 8a. Union: в USER REQUEST есть «объединить»/«единое тело»/«слить»?
        Нет → в коде НЕТ Union/Subtract/Intersect.
[ ] 8b. Fillet: в USER REQUEST есть «скруглить»/«радиус»/fillet?
        Нет → в коде НЕТ ни одного Fillet(...). Эти две проверки
        независимы друг от друга.
[ ] 8c. Chamfer: в USER REQUEST есть «фаска»/«снять фаску»/chamfer?
        Нет → в коде НЕТ Chamfer(...). Параметр называется setback,
        НЕ radius — проверь имя параметра перед выдачей.
[ ] 8d. Shell: в USER REQUEST есть «оболочка»/«тонкостенный»/«полый»?
        Нет → в коде НЕТ Shell(...). faces = список Face, полученных
        через top_face()/bottom_face()/side_face()/circular_face()/
        face_from_edges() — НЕ extrude.body и не список строк.
[ ] 9c. Скругляешь углы БОССА (без Union, без слова «шов»)? Первый
        аргумент Fillet — переменная САМОГО босса (не plate/big_box).
        Рёбра — ТОЛЬКО boss.vertical_edges(), не список строк вручную.
        Несколько боссов — отдельный Fillet на каждый.
[ ] 9d. Цилиндр (Circle-профиль): рёбра торцов — ТОЛЬКО через
        circular_edge(ring=...), буквенные имена ("ab") к нему
        неприменимы.
[ ] 9e. «N деталей по кругу» — твёрдые детали → radial_pattern_frames
        (НЕ holes_in_circle, та для отверстий).
[ ] Отверстие в стенке: u,v В МИЛЛИМЕТРАХ (не 0.5/0.5).
[ ] Отверстие в пластине: point_from_center/holes_in_row, НЕ on_frame.
[ ] Отверстие в боссе: on_frame(u=0, v=0) при u0=v0=0.5.
[ ] Отверстия у углов: dx=a/2-d, dy=b/2-d, НЕ (±d,±d).
[ ] Все числа в формулах (dx, dy, u, v, offset, du...) выведены из
    size_a/side_b/height/length ИЗ ТЕКУЩЕГО ЗАПРОСА, а не скопированы
    из примера промпта (addon_hard_rules п.23).
[ ] «Свободные / дальние / не касающиеся родителя» вертикали пристроя (паттерн B)
    → ["cc1", "dd1"], не vertical_edges().
