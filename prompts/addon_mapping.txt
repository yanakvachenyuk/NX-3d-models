======================================================================
МАППИНГ РУССКОГО ЯЗЫКА → ПАРАМЕТРЫ (обязательно применять)
======================================================================
Пользователь НЕ обязан писать angle=, u0=, v0=. Ты САМ выбираешь
параметры по смыслу фразы. Ниже — жёсткие соответствия.
0. ПОЗИЦИЯ НА ГРАНИ (center_frame) — когда деталь НА грани
   «на верхней грани» / «сверху» / «плашмя» / «бобышка на пластине»
       → center_frame(side='same') + attach, u0=0.5, v0=0.5
   «на нижней грани» / «снизу»
       → center_frame(side='opposite')
   «в центре» / «по центру пластины»
       → du=0, dv=0
   «левее центра на N мм» / «слева от центра на N» / «смещение N влево»
       → du=-N
   «правее центра на N мм» / «справа от центра на N»
       → du=+N
   «выше/ниже центра на N» / «вперёд/назад на N»
       → dv=±N
   «на N влево и M вперёд»
       → du=±N, dv=±M
   N — смещение ЦЕНТРА новой детали от ЦЕНТРА грани.
   «зазор N между боссами» → расстояние центров = N + half1 + half2.
   Несколько боссов на одной грани = несколько attach к ОДНОЙ пластине,
   у каждого свой center_frame(du, dv).
   ЗАПРЕЩЕНО строить второй босс через anchor() или attach к первому боссу,
   если оба должны лежать на одной грани пластины.
1. КУДА РАСТЁТ ПРИСТРОЙКА (angle у anchor) — только ОТ ребра
   «сбоку», «наружу», «к боковой грани», «рядом с ребром»,
   «пристроить к ребру», «от ребра наружу», «стоящий рядом»
       → angle=-90
   «вверх от грани», «перпендикулярно вверх», «торчать вверх»
       → angle=0
   «вниз от грани»
       → angle=180
   «плашмя / продолжая плоскость / в той же плоскости»
       → angle=90 (или center_frame, если лежит на грани целиком)
1a. direction У attach() — ПОЧТИ НИКОГДА не указывай явно
    Правильное направление роста задаётся через angle у anchor()/
    center_frame(), а не через direction у attach(). Если нужно
    «влево» / «вправо» / «вверх» / «вниз» — меняй angle=..., НЕ пиши
    direction=(x,y,z) вручную. direction= у attach() нужен КРАЙНЕ редко
    и только если growth-направление ОТЛИЧАЕТСЯ от нормали уже
    построенного frame — обычных запросов это не касается.
2. ГДЕ СТОИТ ORIGIN ВДОЛЬ РЕБРА (t / offset)
   «от начала ребра» / «от края»
       → t=0, offset=0
   «с отступом N мм от начала» / «отступ N мм от начала ребра»
       → offset=N (t=0)
   «от середины» / «из середины ребра»
       → t=0.5
   «с отступом N мм от середины»
       → t=0.5, offset=N
   НИКОГДА не считай t = мм / длина_ребра вручную.
   Отступ в миллиметрах — ТОЛЬКО через offset=.
3. КУДА РАСТЁТ ПРЯМОУГОЛЬНИК ОТ ORIGIN ВДОЛЬ РЕБРА (u0)
   → u0=0.0 (растёт только вперёд от origin, origin = край пристройки):
     «начинается от этой точки и идёт только вперёд»
     «только вперёд»
     «не центрируется»
     «пусто до точки, потом начинается»
     «отступ N мм, и только потом начало пристройки»
     «с отступом N мм» + нет явных слов «по центру / симметрично»
   → u0=0.5 (origin = центр пристройки):
     «по центру точки» / «центрировать на точке» / «симметрично»
     «от середины» БЕЗ слов «только вперёд / начинается от»
   КРИТИЧНО:
   Если есть «отступ N мм» и при этом НЕ сказано «по центру /
   симметрично / центрировать» → u0=0.0.
   При offset>0 и u0=0.5 половина длины уходит назад за точку
   отступа и вылезает за край большого тела. Это ОШИБКА.
4. ПОПЕРЁК РЕБРА (v0) — зависит от паттерна
   frame = anchor(...) → v0=0.0 (ПАТТЕРН B, от ребра)
   frame = center_frame(...) → u0=0.5, v0=0.5 (ПАТТЕРН A, плашмя)
   НИКОГДА не ставь v0=0.5 вместе с anchor().
   Это самая частая причина «пристройка частично внутри родителя».
5. ШОВ ПОСЛЕ Union
   ПАТТЕРН A (center_frame):
       seam = attachment_seam(child, merged.body)
       Fillet(workPart, target, seam, radius=...)
   ПАТТЕРН B (anchor + attach):
       names = list(dict.fromkeys(child.contact_edges() + child.vertical_edges()))
       edges = child.edges_on(merged.body, names)
       Fillet(workPart, target, edges + target.vertical_edges(), radius=...)
    attach_plate (стенки/борты от ребра):
        ТОЛЬКО через attach_plate_seam (не contact_edges вручную,
        не new_edges, не attachment_seam):
            edges = attach_plate_seam(wall, plate, merged.body,
                                    side=..., edge_name=...)
            Fillet(workPart, plate, edges, radius=...)
        side:
        'outer'  — «наружный» / «внешний» шов / просто «шов»
        'inner'  — «внутренний» шов
        'both'   — «внешний и внутренний» / «оба шва»
        edge_name — то же ребро, что в attach_plate ("ab", "cd", ...).
        attachment_seam и merged.new_edges для attach_plate ЗАПРЕЩЕНЫ.
   attachment_seam при anchor — ЗАПРЕЩЁН.
   contact_edges при center_frame — ЗАПРЕЩЁН.
   Fillet ВСЕГДА на target Union (plate / big_box), НИКОГДА на
   merged и НИКОГДА на wall_* / tools после Union.
   «скруглить шов» / «скруглить наружный/внешний шов» → side='outer'
    «скруглить внутренний шов»                         → side='inner'
    «скруглить внешний и внутренний» / «оба шва»       → side='both'
6. СТЕНКИ ЧЕРЕЗ attach_plate
   «стенка высотой H и толщиной T» / «борт H×T» / «шириной H, толщиной T»
       → attach_plate(..., width=H, thickness=T)
         width = высота стенки (вверх)
         thickness = толщина стенки
       НИКОГДА не менять местами (иначе стенка «ляжет» плашмя).
   «во всю длину ребра» / «на всё ребро»
       → length=None
   Несколько tools в Union (оба варианта допустимы):
       Union(workPart, target, [wall1, wall2])
       Union(workPart, target, wall1, wall2)
  7. Отверстие в пристрое «на расстоянии D от большой детали и по центру»
   → holes=[center_hole(workPart, radius=R, length=L, distance_from_seam=D)]
   L ДОЛЖНО совпадать с length, переданным в rect_profile ТОГО ЖЕ attach().
   НЕ считай u=length/2 и v=D+R вручную — center_hole делает это сама.
   center_hole — ТОЛЬКО для пристроя от ребра (anchor + v0=0) и фразы
«на расстоянии D от … и по центру».
Нужны: radius, length (вдоль ребра), distance_from_seam.
Для бобышки / плашмя (center_frame) «отверстие по центру» —
НЕ center_hole, а:
  holes=[lambda f: Circle.on_frame(workPart, R, f, u=0.0, v=0.0)]
при rect_profile(..., u0=0.5, v0=0.5).
8. НЕСКОЛЬКО БОССОВ / БОБЫШЕК НА ОДНОЙ ГРАНИ (плашмя)
   «на верхней грани» / «сверху» / «на пластине плашмя» / «бобышка сверху»
       → center_frame(side='same') + attach, u0=0.5, v0=0.5
   «на нижней грани» / «снизу пластины»
       → center_frame(side='opposite') + attach, u0=0.5, v0=0.5
   «в центре» / «по центру пластины» / «по центру грани»
       → center_frame(side='same') # du=0, dv=0
   «левее центра на N мм» / «слева от центра на N» / «со смещением N влево»
       → center_frame(side='same', du=-N)
   «правее центра на N мм» / «справа от центра на N» / «со смещением N вправо»
       → center_frame(side='same', du=+N)
   «выше центра на N мм» / «ближе к стороне bc / дальше по ширине»
       → center_frame(side='same', dv=+N) # знак зависит от ориентации;
                                            # если «вдоль короткой стороны вверх» — dv
   «ниже центра на N мм»
       → center_frame(side='same', dv=-N)
   «со смещением N по X и M по Y» / «на N влево и M вперёд»
       → center_frame(side='same', du=±N, dv=±M)
   N — смещение ЦЕНТРА босса от ЦЕНТРА грани (не от края босса, не от края пластины).
      «зазор N мм между боссами» (ДВА одинаковых или разных объекта,
        симметрично по одной оси):
            du = gap_offset(gap=N, size1=<полный размер1>, size2=<полный размер2>)
            frame_l = plate.center_frame(side='same', du=-du)
            frame_r = plate.center_frame(side='same', du=du)
        Передавай ПОЛНЫЕ размеры (20.0, а НЕ 10.0) — функция сама делит
        пополам. НЕ считай half1/half2/center_dist вручную.
   Каждый босс — ОТДЕЛЬНЫЙ attach к ОДНОЙ И ТОЙ ЖЕ пластине.
   ЗАПРЕЩЕНО строить второй босс через anchor() первого босса
   или через attach к уже созданному боссу, если речь о той же грани пластины.
   ЧИСЛО БОССОВ/ПРИСТРОЕК СТРОГО РАВНО ЧИСЛУ, УКАЗАННОМУ В USER REQUEST.
    «две бобышки» → ровно 2 attach. «три бобышки» → ровно 3 attach.
    Пример 2c (три босса: центр + лево + право) — это ШАБЛОН ТОЛЬКО для
    случая, когда пользователь просит именно 3 объекта (центральный +
    два боковых). Он НЕ означает «на любую грань всегда добавляй
    центральный босс». Если просят 2 — центрального НЕТ, только 2 attach.
    Если просят 4 и больше — считай схему их размещения из смысла запроса
    (в ряд / по краям / и т.п.), не добавляй лишних деталей "для симметрии".
9. ОТВЕРСТИЯ В БОССАХ / НА ГРАНИ (уточнение к п.7)
   «в боссе отверстие по центру» / «отверстие в каждом боссе»
       → holes=[lambda f: Circle.on_frame(workPart, R, f, u=0.0, v=0.0)]
         внутри ТОГО ЖЕ attach, которым создаётся босс.
         НЕ center_hole (center_hole только для anchor + v0=0).
   «в центральном боссе R=4, в боковых R=2»
       → у каждого attach свой holes= со своим радиусом.
   «отверстие в пластине по центру»
       → Circle + base.point_from_center() в списке профилей Extrude,
         НЕ holes= у attach.
    «отверстия в ряд в пластине, по центру / симметрично»
       → holes_in_row(workPart, base, radii=R или [R1,R2,...], gap=G)
         (если радиус один и тот же у всех N отверстий — radii=R, n=N)
   «отверстия в ряд С ОТСТУПОМ от края / от короткой стороны / не по центру»
       → holes_in_row(workPart, base, radii=R, gap=G, n=N,
                       align='start', edge_offset=D)
         D — расстояние от короткого края (side_a) до ЦЕНТРА первого
         отверстия. НЕ считай x0 вручную — align='start' делает это сам.
9a. ПОЭЛЕМЕННОЕ СООТВЕТСТВИЕ СПИСКОВ ("N, M, K соответственно" /
    "с радиусами R1, R2, R3" / "диаметры D1 и D2 для...")
    Если в запросе несколько объектов перечислены явно (например, три
    бобышки: центральная, левая, правая) И следом идёт список значений
    с словом «соответственно» / просто перечисление через запятую в том
    же порядке — это ПОЭЛЕМЕННОЕ сопоставление 1-к-1: i-й объект получает
    i-е значение из списка, В ТОМ ЖЕ ПОРЯДКЕ, в котором объекты были
    названы выше в предложении.
    Каждому объекту достаётся РОВНО ОДНО значение из списка — количество
    значений в списке ВСЕГДА равно количеству объектов, если явно не
    сказано иное («в каждой по два отверстия» и т.п.).
    НИКОГДА не вставляй все значения списка (или их часть) в один и тот
    же объект — holes= у каждого attach должен содержать ровно тот
    элемент(ы), что соответствует ИМЕННО этому объекту по порядку.
    Пример: «три бобышки ... с отверстиями R3, R2, R2 соответственно» →
      боссу №1 (первому названному, обычно центральному) → R3
      боссу №2 (второму названному) → R2
      боссу №3 (третьему названному) → R2
      Каждый attach получает holes=[<один Circle.on_frame с соответствующим radius>]
9b. FILLET УГЛОВ БОССА БЕЗ UNION (паттерн A, center_frame, без объединения)
    «скруглить углы бобышки/босса» (без слова «шов», без Union) →
        Fillet(workPart, boss, boss.vertical_edges(), radius=...)
    ЗАПРЕЩЕНО передавать явный список строк-имён рёбер (["aa1","bb1"]
    и т.п.) — только вызов boss.vertical_edges().
    КРИТИЧНО: первый аргумент — ПЕРЕМЕННАЯ САМОЙ БОБЫШКИ (boss/boss_l/
    boss_r), а НЕ plate/big_box. Fillet(workPart, plate, ...) скруглит
    углы ПЛАСТИНЫ, а не бобышки — это грубая ошибка, даже если имена
    рёбер выглядят похоже на пример из anchor-паттерна.
    Если бобышек несколько — ОТДЕЛЬНЫЙ Fillet НА КАЖДУЮ бобышку.
        — ВСЕ 4 вертикальных ребра, т.к. Union нет, «шва» с родителем
        не существует, деление на "aa1","bb1" (шов) vs "cc1","dd1"
        (свободные) относится ТОЛЬКО к паттерну anchor+attach
        (Пример 4), где деталь растёт ОТ ребра родителя.
    Если бобышка ПОСЛЕ Union и просят скруглить именно шов с
    пластиной — тогда attachment_seam(boss, merged.body), см. п.5.
    Не путать «скруглить углы бобышки» (все 4 ребра) со
    «скруглить шов» (только контактная граница с пластиной).
10. СТЕНКИ И БОРТА (дополнение к п.6)
    «стенка на ребре ab» / «борт вдоль ab» / «по всему ребру»
        → attach_plate("ab", length=None, width=H, thickness=T)
    «стенка высотой H толщиной T с отверстием по центру»
        → attach_plate(..., holes=[lambda f: Circle.on_frame(..., u=L/2, v=H/2)])
          L = длина ребра (при length=None — side родителя вдоль ребра).
    «две стенки на противоположных рёбрах» / «на ab и cd»
        → два attach_plate ("ab" и "cd").
    «стенка не на всю длину, а длиной L с отступом N от начала»
        → НЕ attach_plate, а anchor("ab", offset=N, angle=0) + attach
          с rect_profile(length=L, width=H, u0=0, v0=0), thickness=T
          (угол 0 — рост вверх вдоль нормали пластины).
11. ПРИСТРОЙ СБОКУ / ПОД УГЛОМ (кратко, уже есть в п.1–4)
    «пристроить сбоку к ребру» / «рядом с пластиной»
        → anchor(..., angle=-90) + attach, v0=0
    «прилив вверх от ребра» / «ребро вверх»
        → anchor(..., angle=0) + attach
    «от середины ребра только вперёд»
        → t=0.5, u0=0.0
    «от середины ребра симметрично / по центру»
        → t=0.5, u0=0.5
12. НИЖНЯЯ СТОРОНА / ПОВОРОТ
    «босс снизу» / «на нижней грани»
        → center_frame(side='opposite')
    «повернуть босс на 45° в плоскости грани»
        → center_frame(..., spin=45.0)
    «приподнять над гранью на G мм» (зазор)
        → center_frame(..., lift=height_пластины + G)
          (по умолчанию lift=height родителя — вплотную)

======================================================================
ОТВЕРСТИЯ В УГЛАХ ПЛАСТИНЫ (прямоугольник side_a × side_b)
======================================================================
Профиль центрирован: центр = (0,0), края при ±side_a/2 и ±side_b/2.

«в углах / у углов / по углам» + «отступ d от краёв» / «на d мм от краёв»:
  dx = side_a/2 - d
  dy = side_b/2 - d
  четыре отверстия:
    point_from_center(+dx, +dy)
    point_from_center(+dx, -dy)
    point_from_center(-dx, +dy)
    point_from_center(-dx, -dy)

Пример: пластина 80×40, отступ 10 мм от краёв
  → dx=30, dy=10 → (±30, ±10), НЕ (±10, ±10)

«смещение N от центра» в углах:
  - если указаны ДВЕ оси («N по длине и M по ширине») → (±N, ±M)
  - если одно N на прямоугольнике — НЕ использовать как (±N,±N)
    (это не углы). Пересчитать из отступа от краёв или спросить по смыслу:
    углы с отступом d → (±(a/2-d), ±(b/2-d))

Разные отступы: «d1 от коротких сторон, d2 от длинных»
  (side_a вдоль «длины», side_b вдоль «ширины»):
  dx = side_a/2 - d1, dy = side_b/2 - d2

Только point_from_center. ЗАПРЕЩЕНО: center=(70,10), (±10,±10) «как углы»
при a≠b и отступе 10 от краёв.
