======================================================
БАЗОВЫЙ ПРИНЦИП (соблюдать всегда)
======================================================

1. Одна деталь = один Extrude (Parallelogram / Polygon / Circle / Triangle).
2. Вторая и последующие детали присоединяются ТОЛЬКО через методы
   Extrude: attach_plate, attach, anchor, center_frame.
3. Несколько тел объединяются / вычитаются через Union / Subtract / Intersect.
4. Скругление рёбер стыка двух пластин → classify_seam.
   Все остальные рёбра → имена, edges_after_boolean, new_edges.
5. КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО:
   - писать Polygon с явными координатами [(0,0,0), ...], если можно
     использовать Parallelogram или rect_profile
   - самостоятельно ставить rise='opposite' или другие параметры,
     которые пользователь не просил
   - считать координаты рёбер вручную, если есть classify_seam
     или edges_after_boolean
  - вручную считать координаты точек на стороне профиля (синус/косинус/
    вручную выведенная нормаль), если можно использовать
    profile.edge_frame(index) / profile.edge_frame_by_name("ab")

======================================================
БУКВЕННАЯ РАЗМЕТКА Extrude
======================================================

Вершины: a, b, c, d... (низ) и a1, b1, c1, d1... (верх).
Рёбра: "ab", "bc", "cd", "da", "a1b1", "aa1", "bb1" и т.д.
Индекс профиля: 0 — внешний контур, 1, 2... — отверстия.

======================================================
МЕТОДЫ Extrude
======================================================

attach_plate(edge_name, length, width, thickness, rise='same', grow='auto', overlap='auto', profile_index=0, holes=None)
    Прямоугольная пластина к ребру. Использовать ВСЕГДА для прямоугольных пластин.

attach(build, thickness, frame=None, edge_name=None, profile_index=0, t=0.0, offset=0.0, angle=0.0, lift=0.0, direction=None, holes=None)
    Любая фигура. build = функция frame → Profile.

anchor(edge_name, profile_index=0, t=0.0, offset=0.0, angle=0.0, lift=0.0) → Frame
    angle=0 — вдоль экструзии, 90 — плашмя, 180 — обратно, любое другое — произвольный угол.

center_frame(profile_index=0, side='same'/'opposite', spin=0.0, du=0.0, dv=0.0, lift=None) → Frame
    Деталь плашмя на грани.

find_edge / edge_points / vertex — геометрия по имени.

======================================================
ВЫБОР РЁБЕР ПОСЛЕ СТЫКОВКИ ПЛАСТИН
======================================================

Когда две пластины соединены через attach_plate + Union и нужно
скруглить стык (внешнее и внутреннее ребро):

seam = classify_seam(child, merged.body, "ab", parent_extrude=родитель)
Fillet(workPart, base, seam["outer"] + seam["inner"], радиус)

ВСЕГДА передавай parent_extrude.
======================================================
ЦЕПОЧКА ИЗ НЕСКОЛЬКИХ ПЛАСТИН
======================================================

Каждую новую пластину создавай от уже существующего Extrude,
сразу делай Union, сохраняй child-переменные.
Для каждого стыка — свой classify_seam.
