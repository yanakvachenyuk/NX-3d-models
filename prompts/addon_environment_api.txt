ОКРУЖЕНИЕ
======================================================================
Session, workPart и все публичные имена из nx_primitives уже подставлены
автоматически ДО твоего кода. В пространстве имён гарантированно доступны:
    Triangle, Parallelogram, Polygon, Circle, Line,
  Extrude, Fillet, Chamfer, Shell, Union, Subtract, Intersect, Boolean,
  Frame, Hide, rect_profile, center_hole,
  attachment_seam, edges_after_boolean, edges_in_box, edges_near,
  attach_plate_seam, gap_offset, holes_in_row, holes_in_circle
НЕ пиши:
  import NXOpen
  from nx_primitives import ...
  theSession = NXOpen.Session.GetSession()
  workPart = theSession.Parts.Work
Начинай код сразу с построения геометрии. Никогда не используй «голый»
NXOpen напрямую — всё строится только через классы/функции ниже.

======================================================================
ЧТО ТАКОЕ Extrude И ПОЧЕМУ ОН ЦЕНТРАЛЬНЫЙ ОБЪЕКТ БИБЛИОТЕКИ
======================================================================
Любое тело строится в два шага:
1. Плоский 2D-контур (Polygon / Circle / Triangle / Parallelogram) — линии, не тело.
2. Extrude(workPart, [контур, ...], height, direction) — объёмное тело выдавливанием.

Extrude(workPart, profiles, height, direction=(0.0,0.0,1.0), draft_angle=0.0)
    profiles — список профилей. ПЕРВЫЙ — внешний контур тела.
                ОСТАЛЬНЫЕ — вычитаемые контуры (отверстия) внутри него.
    height — высота выдавливания (число, не строка).
    direction — вектор (x,y,z), куда растёт тело. По умолчанию (0,0,1).
    draft_angle — угол уклона боковых стенок в градусах (0.0 по
    умолчанию — без уклона). Указывать ЯВНО только если в запросе
    есть «уклон»/«конусность»/«литейный уклон»/draft.
Результат — объект Extrude:
    .body — NXOpen.Body (готовое тело)
    .profiles, .height, .direction
    .profile_labels — список словарей {имя_вершины: 3D-точка} на профиль
    .labels — то же что profile_labels[0]

БУКВЕННАЯ РАЗМЕТКА ВЕРШИН: низ a,b,c,d,...; верх a1,b1,c1,d1,...
ИМЕНА РЁБЕР: "ab","bc",... — низ; "a1b1",... — верх; "aa1","bb1",... — вертикали
Готовые списки: extrude.bottom_edges() / top_edges() / vertical_edges() / contact_edges()

--- Frame ---
Frame(origin, u, v, normal=None)
    .point(u=0.0, v=0.0, w=0.0)
    .points(local_xy)
    .flipped() -> Frame
        Новый Frame с той же origin/u/v, но normal развёрнута на 180°.
        Используй, когда деталь должна расти НАВСТРЕЧУ обычному
        направлению нормали frame (anchor angle=0 "вверх от грани",
        center_frame "внутрь оболочки/полости" и т.п.) — см. п.1a, 1b.
        ЕДИНСТВЕННЫЙ способ развернуть направление роста; direction=
        у attach() вручную НЕ указывается.

--- Extrude: стыковка ---
Extrude.find_edge(name, profile_index=0)
Extrude.edge_points(name, profile_index=0)
Extrude.vertex(name, profile_index=0)
Extrude.bottom_edges / top_edges / vertical_edges / contact_edges
Extrude.edges_on(body, names, profile_index=0)
Extrude.attach_plate(edge_name, length, width, thickness,
                      rise='same', grow='auto', overlap='auto',
                      profile_index=0, holes=None)
    length=None → во всю длину ребра. width → ВЫСОТА стенки (вверх).
    thickness → ТОЛЩИНА стенки. Перевод фраз в эти параметры — addon_mapping п.6.
Extrude.anchor(edge_name, profile_index=0, t=0.0, offset=0.0,
               angle=0.0, lift=0.0)
    t — доля 0..1; offset — мм. angle: 0 вверх, -90 наружу вбок,
    90 плашмя, 180 вниз. Перевод фраз — addon_mapping п.1-2.
Extrude.center_frame(profile_index=0, side='same', spin=0.0,
                      du=0.0, dv=0.0, lift=None)
    Перевод фраз (du/dv/side/spin/lift) — addon_mapping п.0,8,12.
Extrude.attach(build, thickness, frame=None, edge_name=None,
               profile_index=0, t=0.0, offset=0.0, angle=0.0,
               lift=0.0, direction=None, holes=None)
    build(frame) -> Profile, строить от f. holes — список таких же функций.
    direction — почти никогда не указывай явно, см. addon_mapping п.1a.

--- Extrude: доступ к граням (нужен для Shell / для сложных Fillet-запросов) ---
Extrude.top_face(profile_index=0) -> NXOpen.Face
Extrude.bottom_face(profile_index=0) -> NXOpen.Face
Extrude.side_face(edge_name, profile_index=0) -> NXOpen.Face
    edge_name — имя нижнего ребра ("ab") ИЛИ имя самой боковой грани
    ("abb1a1") — оба варианта равнозначны.
Extrude.face_from_edges(edge_names, profile_index=0) -> NXOpen.Face
    Грань, содержащая ВСЕ переданные рёбра (имена/кортежи/готовые Edge).
Extrude.side_faces(profile_index=0) -> list[str]
    Список имён всех боковых граней профиля.

--- Extrude: цилиндр (профиль Circle) ---
Extrude.circular_edge(profile_index=0, ring='bottom', tol=1.0) -> NXOpen.Edge
    Круглое ребро (верх/низ) экструзии профиля-окружности. У цилиндра
    НЕТ буквенных имён ("ab" и т.п.) — рёбра торцов доступны ТОЛЬКО так.
Extrude.circular_face(profile_index=0, ring='bottom', tol=1.0) -> NXOpen.Face
    Торцевая грань цилиндра (для Shell/face_from_edges).
Extrude.radial_frame(profile_index=0, angle=0.0, t=0.5, lift=0.0) -> Frame
    Frame НА БОКОВОЙ поверхности цилиндра — аналог anchor(), но для
    круглого профиля. angle — угол вокруг оси, t — доля высоты (0..1),
    normal смотрит наружу. Используется с attach() для детали, растущей
    сбоку от цилиндра.
Extrude.radial_pattern_frames(count, circle_radius, profile_index=0,
                               side='same', start_angle=0.0,
                               spin_along_radius=True, lift=None) -> list[Frame]
    N Frame по окружности НА ГРАНИ (аналог center_frame, но паттерном
    по кругу) — для N твёрдых деталей (боссов/рёбер жёсткости),
    расположенных по кругу. Каждый Frame передаётся в attach(frame=...).
    ЭТО НЕ ТО ЖЕ САМОЕ, что holes_in_circle() — та строит ОТВЕРСТИЯ
    (Circle для вычитания), а не твёрдые detail-объекты.

--- Скругление ---
Fillet(workPart, extrude, edges, radius)
    extrude — ТОЛЬКО Extrude (target), НЕ Union/merged.
    edges — строки, кортежи (имя, index), или готовые NXOpen.Edge.

--- Фаска ---
Chamfer(workPart, extrude, edges, setback)
    extrude — ТОЛЬКО Extrude (target), НЕ Union/merged (та же логика, что Fillet).
    edges — строки/кортежи (имя, index)/готовые NXOpen.Edge, как в Fillet.
    setback — отступ фаски в мм (НЕ radius!). Фаска симметричная (45°).

--- Оболочка ---
Shell(workPart, extrude, faces, thickness)
    extrude.body должен быть активным (не suppressed), как у Fillet/Chamfer.
    faces — список УДАЛЯЕМЫХ (открываемых) граней, каждая — готовый
    NXOpen.Face, полученный через extrude.top_face()/.bottom_face()/
    .side_face(edge_name)/.circular_face()/.face_from_edges(edge_names).
    thickness — толщина стенки в мм, материал добавляется НАРУЖУ.

--- Булевы операции ---
Union(workPart, target, tools, *more_tools, tolerance=0.01)
Subtract(workPart, target, tools, *more_tools, tolerance=0.01)
Intersect(workPart, target, tools, *more_tools, tolerance=0.01)
    tools — один Extrude/Body ИЛИ список. Несколько tools:
      Union(workPart, plate, [wall_ab, wall_cd])
      Union(workPart, plate, wall_ab, wall_cd)
    Результат: .body, .new_edges, .removed_edges_count — НЕ Extrude
    (нет find_edge/anchor/attach, см. addon_hard_rules п.17).
    После операции tools suppressed.
attachment_seam(child, parent_body, profile_index=0, ring="bottom")
    ТОЛЬКО паттерн A (center_frame). Для anchor/attach_plate не использовать.
edges_after_boolean(child, target_body, edge_names, profile_index=0)
edges_in_box(body, p_min, p_max)
edges_near(body, point, tol=1.0)
attach_plate_seam(wall, plate, parent_body, side='outer', edge_name='ab', tol=1.5)
    Швы после attach_plate + Union. side: 'outer'|'inner'|'both'.
    edge_name — ребро из attach_plate. Возвращает список NXOpen.Edge для Fillet.

--- Прочее ---
rect_profile(workPart, frame, length, width, u0=0.0, v0=0.0)
    u0=0,v0=0 — от origin в +u/+v (паттерн B). u0=0.5,v0=0.5 — центр
    (паттерн A). u0=0.5,v0=0 — центр по u, от origin по v (B «по центру»).
    Перевод фраз в u0/v0 — addon_mapping п.3-4.
center_hole(workPart, radius, length, distance_from_seam)
    Функция-отверстие для holes= у attach(). length — тот же, что в
    rect_profile того же attach(). Отверстие по центру вдоль ребра
    (u=length/2), на distance_from_seam от стыка (radius добавляется
    сам). Только для rect_profile(..., u0=0.0, v0=0.0).
holes_in_row(workPart, profile, radii, gap, y=0.0, n=None,
             align='center', edge_offset=None, x0=None)
    N отверстий в ряд с равным шагом gap. profile — ClosedProfile
    (Parallelogram/Triangle/Polygon), НЕ Circle. Возвращает список
    готовых Circle: Extrude(workPart, [base] + holes_in_row(...), ...).
    radii — список чисел, ИЛИ одно число + n=.
    align='center' (умолч.) центрирует ряд; 'start'+edge_offset
    сдвигает раскладку ВНУТРИ ряда от короткого края. y сдвигает ВЕСЬ
    РЯД целиком поперёк. Разбор формулировок запроса (align vs y) —
    addon_mapping п.9, код-примеры — addon_anti_examples.
holes_in_circle(workPart, profile, radii, circle_radius: float,
                    n: int = None, start_angle: float = 0.0,
                    center=(0.0, 0.0))
    Готовые Circle для N отверстий, равномерно расположенных по окружности
        (болтовой круг) радиуса circle_radius, вокруг center (смещение от
        центра profile - как в holes_in_row).

        radii:
            - список чисел (длина списка = число отверстий), ЛИБО
            - одно число - тогда ОБЯЗАТЕЛЕН n= (сколько отверстий создать),
            все N отверстий получат этот радиус.

        start_angle - угол ПЕРВОГО отверстия, в градусах, от оси X профиля
                    (0 = вправо от center), далее отверстия идут против
                    часовой стрелки с равным шагом 360/n.

        Возвращает список ГОТОВЫХ Circle - используй как и holes_in_row:
            Extrude(workPart, [base] + holes_in_circle(workPart, base, radii=3.0, circle_radius=40.0, n=6), ...)
Hide(theSession, *profiles)
gap_offset(gap, size1, size2=None) -> float
    du для ДВУХ объектов, симметрично расположенных с зазором gap
    между ближними гранями. size1/size2 — ПОЛНЫЕ размеры (не половины).
    Использование — addon_mapping п.8, пример — addon_examples 2d.

======================================================================
АЛГОРИТМ РЕШЕНИЯ ЗАДАЧИ (следуй по порядку)
======================================================================
1. Разбей запрос на отдельные тела (каждое = контур + Extrude).
2. Первое тело — с нуля. Остальные — anchor/center_frame/attach/
   attach_plate по правилу из system_base «ГЛАВНАЯ РАЗВИЛКА»; build
   всегда от f; отверстия только holes=; отступ только offset=.
3. Union — только если явно просили объединить (addon_hard_rules п.1).
4. Fillet — только если явно просили скруглить, шов — по паттерну
   (addon_mapping п.5), Fillet(workPart, target, edges, radius).
5. Числа — float-совместимые, не строки.
6. Перед нетривиальным anchor/attach — короткий комментарий: где
   origin, куда растёт, какой u0/v0/angle и почему.
7. Самопроверка перед выдачей — см. блок МИНИМАЛЬНОСТЬ в system_base
   и addon_checklist целиком.

ПРИСТРОЙ К ГРАНИ/РЕБРУ — ЕДИНСТВЕННЫЙ ПАТТЕРН

# ПРАВИЛЬНО:
frame = big_box.anchor("abb1a1", offset=10.0, angle=-90.0)
small_box = big_box.attach(
    lambda f: rect_profile(workPart, f, length=8.0, width=12.0, u0=0.0, v0=0.0),
    thickness=5.0, frame=frame,
)
# НЕПРАВИЛЬНО:
small_base = Parallelogram(...)
small_box = small_base.Extrude(...)  # AttributeError — метода нет

================================================================================
СВОБОДНЫЕ / ДАЛЬНИЕ вертикальные рёбра пристроя (attach от ребра, v0=0)
================================================================================
  → ТОЛЬКО ["cc1", "dd1"] — НЕ vertical_edges() (там есть aa1,bb1 на шве)
    и НЕ ["aa1", "bb1"] (это как раз рёбра стыка)
  contact/на шве: aa1, bb1 (+ часто ab, a1b1) = contact_edges()
  Пример:      Fillet(workPart, small_box, ["cc1", "dd1"], radius=1.5)
  Антипример:  Fillet(workPart, small_box, small_box.vertical_edges(), ...)  # скруглит и шов
               Fillet(workPart, small_box, ["aa1", "bb1"], ...)  # только шов
